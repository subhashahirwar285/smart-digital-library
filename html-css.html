CHAPTER 01

Introduction to Web Development

1.1 What is Web Development?

Web development is the process of creating, building and maintaining websites and web applications. It includes designing the appearance of a website, writing its code, managing information and making sure that the website works correctly in different browsers and devices.

A website may contain text, images, videos, buttons, forms, menus and interactive features. These elements work together to provide information and services to users.

1.2 What is a Website?

A website is a collection of related web pages available through a common domain name. For example, an educational website may contain a home page, courses page, contact page and student login page.

1.3 What is a Web Page?

A web page is a single document that can be viewed using a web browser. It is commonly written using HTML and styled using CSS. A browser reads the document and displays its content to the user.

1.4 Front-End Development

Front-end development deals with the part of a website that users can see and interact with. It includes page structure, colours, typography, navigation, buttons and layouts.

  • HTML: Defines the structure and content.
  • CSS: Controls the visual presentation.
  • JavaScript: Adds behaviour and interactivity.

1.5 Back-End Development

Back-end development manages the server-side operations of a website. It may handle user accounts, authentication, databases, file storage and business logic. Common back-end technologies include Node.js, PHP, Python, Java and server-side frameworks.

1.6 How a Website Works

  1. A user enters a website address in a browser.
  2. The browser requests the website from a server.
  3. The server sends the required files or data.
  4. The browser reads HTML, CSS and JavaScript.
  5. The browser displays the web page.

Introduction to HTML

2.1 What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages. HTML tells a browser what type of content is present, such as headings, paragraphs, images, links, lists and tables.

HTML is a markup language rather than a general-purpose programming language. It uses elements and tags to describe the meaning and structure of content.

2.2 History of HTML

HTML was developed by Tim Berners-Lee while working on the World Wide Web. It has evolved through several versions. HTML5 introduced important features for modern websites, including semantic elements, audio, video and improved form controls.

2.3 What are HTML Tags?

HTML tags are keywords written inside angle brackets. Most elements use an opening tag and a closing tag. The closing tag contains a forward slash.

<p>This is a paragraph.</p>

In this example, <p> is the opening tag, the sentence is the content, and </p> is the closing tag.

2.4 HTML Elements

An HTML element generally consists of an opening tag, content and a closing tag. Some elements, such as images and line breaks, are void elements and do not have closing tags.

<h1>Welcome to My Website</h1>
<p>Learn HTML step by step.</p>
<hr>
<img src="photo.jpg" alt="Sample photo">

2.5 HTML Attributes

Attributes provide additional information about an element. They are written inside the opening tag and usually contain a name and value.

<a href="https://example.com" target="_blank">
    Visit Website
</a>

<img src="book.jpg" alt="Programming Book" width="200">

Here, href specifies a link destination. The src attribute specifies an image file, while alt provides alternative text.

Important: HTML tags should be properly nested. Always use meaningful elements and provide alternative text for informative images.

HTML Document Structure

3.1 Basic Structure of an HTML Document

Every standard HTML document follows a basic structure. This structure helps browsers understand the document type, language, metadata and visible content.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome</h1>
    <p>This is my first web page.</p>
</body>
</html>

3.2 Explanation of Document Elements

  • <!DOCTYPE html>: Declares that the document uses HTML5.
  • <html>: The root element of the document.
  • <head>: Contains metadata and linked resources.
  • <meta>: Provides information about the document.
  • <title>: Defines the browser tab title.
  • <body>: Contains the visible page content.

3.3 Headings

HTML provides six heading levels, from H1 to H6. H1 represents the highest-level heading, while H6 represents the lowest-level heading. Headings create a logical content hierarchy.

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection Heading</h3>

3.4 Paragraphs and Line Breaks

The paragraph element is used for blocks of text. The line break element moves following content to a new line without creating a new paragraph.

<p>HTML is used to structure content.</p>
<p>CSS is used to style content.</p>

First Line<br>
Second Line

3.5 Semantic HTML

Semantic HTML elements describe the meaning of different parts of a page. They help browsers, search engines and assistive technologies understand the page structure.

<header>Website Header</header>
<nav>Navigation Links</nav>
<main>
    <section>
        <h2>About Us</h2>
        <p>Information about our website.</p>
    </section>
</main>
<footer>Copyright Information</footer>

3.6 Semantic and Non-Semantic Elements

Elements such as <header>, <main> and <article> have a clear meaning. Elements such as <div> and <span> are generic containers.

CHAPTER 04

Text, Links and Lists

4.1 Text Formatting

HTML provides elements for giving text special meaning or presentation. For example, strong indicates importance, while em indicates emphasis.

<p>This is <strong>important</strong> text.</p>
<p>This word is <em>emphasized</em>.</p>
<p>Water formula: H<sub>2</sub>O</p>
<p>Mathematics: X<sup>2</sup></p>
<p><mark>Highlighted text</mark></p>

4.2 Hyperlinks

A hyperlink connects one web resource to another. The anchor element creates hyperlinks. Its href attribute specifies the destination.

<a href="https://www.example.com">
    Open Example Website
</a>

<a href="about.html">About Us</a>

<a href="mailto:info@example.com">
    Send Email
</a>

Links can point to external websites, pages within the same website, email addresses or specific sections of a page.

4.3 Ordered Lists

An ordered list displays items in a sequence, usually with numbers or letters.

<ol>
    <li>Open the editor.</li>
    <li>Create an HTML file.</li>
    <li>Write HTML code.</li>
    <li>Open it in a browser.</li>
</ol>

4.4 Unordered Lists

An unordered list displays items without a specific numerical order. Browsers usually show bullet points.

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

4.5 Description Lists

A description list is useful for displaying terms and their explanations.

<dl>
    <dt>HTML</dt>
    <dd>Defines the structure of web pages.</dd>

    <dt>CSS</dt>
    <dd>Controls the appearance of web pages.</dd>
</dl>

4.6 Nested Lists

A list can contain another list inside one of its items. This is useful for representing categories and subcategories.

<ul>
    <li>Web Development
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>

CHAPTER 05

Images, Audio and Video

5.1 Adding Images

Images make websites more informative and visually attractive. HTML uses the image element to display an image file. The src attribute specifies the file location, and alt provides alternative text.

<img src="library.jpg"
     alt="A digital library"
     width="400"
     height="250">

5.2 Image Paths

An image can be stored in the same folder as the HTML file or inside another folder. A relative path identifies the image location in relation to the current document.

<!-- Image in the same folder -->
<img src="book.jpg" alt="Book">

<!-- Image inside an images folder -->
<img src="images/book.jpg" alt="Book">

5.3 Importance of Alternative Text

Alternative text describes an image when it cannot be displayed. Screen readers can also use it to communicate image information to people who cannot see the image. Decorative images may use an empty alt attribute.

5.4 Adding Audio

The audio element allows a web page to include sound files. The controls attribute displays browser playback controls.

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

5.5 Adding Video

The video element displays video content directly on a web page. Common attributes include controls, width, height, poster and muted.

<video width="500" controls poster="cover.jpg">
    <source src="lesson.mp4" type="video/mp4">
    Your browser does not support video.
</video>

5.6 Figure and Caption

The figure element groups media content with a caption. The figcaption element provides the caption.

<figure>
    <img src="computer.jpg" alt="Computer"
         width="300">
    <figcaption>
        Figure 1: A desktop computer.
    </figcaption>
</figure>
Best Practice: Use descriptive alt text, optimise image file sizes and choose suitable media formats to improve accessibility and page loading.

HTML Tables and Forms

6.1 Introduction to HTML Tables

HTML tables display information in rows and columns. They are useful for structured data such as student records, book inventories, marksheets and schedules.

The table element creates the table. The tr element creates a row, th creates a header cell and td creates a data cell.

6.2 Creating a Table

<table border="1">
    <tr>
        <th>Student Name</th>
        <th>Course</th>
        <th>Marks</th>
    </tr>
    <tr>
        <td>Rahul</td>
        <td>BCA</td>
        <td>85</td>
    </tr>
    <tr>
        <td>Aman</td>
        <td>BCA</td>
        <td>90</td>
    </tr>
</table>

6.3 Table Sections

Large tables can use thead, tbody and tfoot to group header rows, body rows and footer rows. These elements make the table structure easier to understand.

6.4 Introduction to HTML Forms

Forms collect information from users. They are commonly used for registration, login, feedback, search and contact pages. A form may contain text fields, email fields, password fields, checkboxes, radio buttons and submit buttons.

6.5 Creating a Registration Form

<form action="/register" method="post">

    <label for="name">Full Name:</label>
    <input type="text" id="name"
           name="name" required>

    <label for="email">Email:</label>
    <input type="email" id="email"
           name="email" required>

    <label for="password">Password:</label>
    <input type="password" id="password"
           name="password" required>

    <button type="submit">Register</button>
</form>

6.6 Important Input Types

6.7 GET and POST Methods

The GET method generally requests information from a server. Form data sent using GET is commonly included in the URL. The POST method sends data in the request body and is commonly used for submitting form information.

Security Note: The POST method alone does not encrypt information. Websites should use HTTPS and proper server-side validation. Passwords must be securely handled by the back end.

6.8 Form Validation

HTML provides attributes such as required, minlength, maxlength and pattern for basic browser-side validation. Server-side validation is also necessary because browser validation can be bypassed.

Introduction to CSS

7.1 What is CSS?

CSS stands for Cascading Style Sheets. It is used to control the visual appearance of HTML documents. CSS can change colours, fonts, spacing, borders, backgrounds, layouts and responsive behaviour.

HTML describes what content is present, while CSS describes how that content should look.

7.2 Basic CSS Syntax

A CSS rule contains a selector and a declaration block. Each declaration contains a property and a value.

p {
    color: blue;
    font-size: 18px;
}
  • Selector: Selects the HTML element.
  • Property: Identifies what should change.
  • Value: Defines the new setting.

7.3 Three Ways to Apply CSS

1. Inline CSS: Written directly inside an HTML element using the style attribute.

<p style="color: blue;">
    This is a blue paragraph.
</p>

2. Internal CSS: Written inside a style element in the document head.

<head>
    <style>
        h1 {
            color: green;
        }
    </style>
</head>

3. External CSS: Written in a separate .css file and connected using a link element.

<link rel="stylesheet" href="style.css">

External CSS is useful for maintaining consistent styles across multiple pages.

7.4 CSS Colours

CSS supports named colours, hexadecimal values, RGB and HSL colour formats.

h1 {
    color: navy;
}

p {
    color: #333333;
}

button {
    background-color: rgb(21, 101, 192);
}

7.5 CSS Backgrounds

Background properties control the background colour and images of an element.

body {
    background-color: #f0f5fb;
}

.banner {
    background-image: url("banner.jpg");
    background-size: cover;
    background-position: center;
}

7.6 CSS Fonts and Text

CSS provides properties to control font family, size, weight, alignment, line height and text decoration.

p {
    font-family: Arial, sans-serif;
    font-size: 16px;
    font-weight: normal;
    line-height: 1.6;
    text-align: justify;
}

7.7 Why Use External CSS?

  • It keeps HTML and design separate.
  • It makes code easier to maintain.
  • One stylesheet can style many pages.
  • It supports a consistent website design.

CHAPTER 08

CSS Selectors and Properties

8.1 What are CSS Selectors?

CSS selectors identify which HTML elements should receive a particular style. Different selectors are useful for styling individual elements, groups of elements or elements with specific relationships.

8.2 Element Selector

An element selector selects all elements with a given tag name.

p {
    color: #333;
}

8.3 Class Selector

A class selector selects elements with a particular class attribute. A class name begins with a dot in CSS.

.highlight {
    background-color: yellow;
    padding: 10px;
}
<p class="highlight">
    Important information
</p>

8.4 ID Selector

An ID selector targets an element with a specific id attribute. It begins with a hash symbol.

#main-heading {
    color: darkblue;
}

8.5 Universal Selector

The universal selector matches all elements.

* {
    box-sizing: border-box;
}

8.6 Grouping Selector

Multiple selectors can share the same declarations by separating them with commas.

h1, h2, h3 {
    font-family: Arial, sans-serif;
    color: navy;
}

8.7 Descendant Selector

A descendant selector selects elements located anywhere inside another element.

article p {
    line-height: 1.8;
}

8.8 Pseudo-Classes

Pseudo-classes select elements based on a particular state or condition. They are useful for interactive designs.

a:hover {
    color: red;
}

button:focus {
    outline: 2px solid blue;
}

li:first-child {
    font-weight: bold;
}

8.9 CSS Specificity and Cascade

When multiple CSS rules apply to the same element, the browser uses the cascade to determine which declaration takes effect. Specificity is one factor in this decision. In general, ID selectors have greater specificity than class selectors, and class selectors have greater specificity than element selectors. The origin, importance and order of declarations also matter.

CHAPTER 09

CSS Box Model

9.1 Introduction to the Box Model

In CSS, every element is represented as a rectangular box. The CSS box model explains how the dimensions and spacing of that box are calculated. It consists of four main areas: content, padding, border and margin.

9.2 Content

The content area contains the actual text, image or other material inside an element. The width and height properties usually control this area when using the default content-box model.

9.3 Padding

Padding is the space between the content and its border. It creates inner spacing.

.card {
    padding: 20px;
}

9.4 Border

A border surrounds the content and padding. CSS allows developers to control its width, style and colour.

.card {
    border: 2px solid #1565c0;
}

9.5 Margin

Margin is the space outside the border. It separates one element from other elements.

.card {
    margin: 20px;
}

9.6 Complete Box Model Example

.box {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 15px;
}

With the default content-box model, the total horizontal space occupied by this box is 300 + 40 + 10 + 30 = 380 pixels, excluding any effects from neighbouring layout rules.

9.7 Box-Sizing Property

The box-sizing property controls how the width and height of an element are calculated. The border-box value includes padding and border inside the declared width and height.

* {
    box-sizing: border-box;
}

This rule makes layouts easier to manage because the declared width includes the content, padding and border.

9.8 Display Property

The display property controls how an element participates in layout. Common values include block, inline, inline-block, flex, grid and none.

  • Block: Usually starts on a new line and takes available width.
  • Inline: Flows within text and does not normally accept width and height in the same way as block elements.
  • Inline-block: Flows inline while allowing width and height.
  • None: Removes the element from the layout.
Practical Tip: The universal box-sizing rule is commonly used in modern stylesheets to make sizing calculations more predictable.

CHAPTER 10

Flexbox and CSS Grid

10.1 Introduction to CSS Layout

CSS layout systems help developers arrange content on a web page. Modern websites often use Flexbox and CSS Grid to create organised layouts that adapt to different screen sizes.

10.2 What is Flexbox?

Flexbox, or the Flexible Box Layout, is a one-dimensional layout system. It is designed to arrange items in a row or a column and control their alignment and spacing.

10.3 Creating a Flex Container

.container {
    display: flex;
    gap: 15px;
    justify-content: center;
    align-items: center;
}

.item {
    padding: 20px;
    background: #e3f2fd;
}

The display property activates Flexbox. The gap property creates spacing between items. Justify-content controls alignment along the main axis, while align-items controls alignment along the cross axis.

10.4 Important Flexbox Properties

PropertyPurpose
flex-directionSets row or column direction
justify-contentAligns items along the main axis
align-itemsAligns items along the cross axis
flex-wrapAllows items to wrap
gapSets spacing between items
flex-growControls how an item grows

10.5 What is CSS Grid?

CSS Grid is a two-dimensional layout system. It can organise content into rows and columns at the same time. It is especially useful for page layouts, galleries and card collections.

10.6 Creating a Grid Layout

.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

.grid-item {
    background: #e3f2fd;
    padding: 25px;
}

The repeat function creates repeated column definitions. The fr unit represents a fraction of the available space.

10.7 Flexbox vs Grid

FlexboxCSS Grid
One-dimensional layoutTwo-dimensional layout
Works mainly in a row or columnWorks with rows and columns
Useful for navigation and alignmentUseful for complete page and card layouts
Arranges items along one main axisControls both axes together

10.8 When to Use Each Layout

Use Flexbox when arranging a group of items in one direction, such as a navigation bar or a row of buttons. Use Grid when arranging content in a structured row-and-column layout, such as a dashboard or image gallery. Both systems can be used together in the same website.

CHAPTER 11

Responsive Web Design

11.1 What is Responsive Web Design?

Responsive Web Design is an approach to building websites that adapt to different screen sizes and devices. A responsive website should remain readable and usable on desktop computers, laptops, tablets and smartphones.

11.2 Why is Responsive Design Important?

  • People access websites using different devices.
  • Content should remain readable on small screens.
  • Navigation should be easy to use.
  • Images and layouts should fit the available space.
  • Users should not need unnecessary horizontal scrolling.

11.3 Viewport Meta Tag

The viewport meta tag helps browsers display pages using the device's screen width. It is an important part of responsive design.

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

11.4 Flexible Widths

Responsive layouts often use percentages, flexible units and maximum widths instead of fixed dimensions everywhere.

.container {
    width: 90%;
    max-width: 1100px;
    margin: auto;
}

img {
    max-width: 100%;
    height: auto;
}

11.5 Media Queries

Media queries allow CSS rules to apply only when certain conditions are met, such as a maximum viewport width.

.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

@media (max-width: 768px) {
    .cards {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (max-width: 480px) {
    .cards {
        grid-template-columns: 1fr;
    }
}

In this example, the layout changes from three columns to two columns on medium screens and one column on smaller screens.

11.6 Mobile-First Design

Mobile-first design means starting with the layout for smaller screens and then adding styles for larger screens. This approach encourages developers to focus on essential content and simple layouts.

11.7 Responsive Images

Images should fit their containers without overflowing. The max-width property is commonly used for this purpose. For different image sources at different screen sizes, HTML also provides the picture and srcset features.

11.8 Testing Responsive Websites

  1. Open the website in a browser.
  2. Open browser developer tools.
  3. Enable the device toolbar.
  4. Select different device sizes.
  5. Check text, images, navigation and spacing.
  6. Fix any overflow or readability problems.

Glossary

Attribute: Additional information provided inside an HTML element.

Browser: Software used to access and display websites.

CSS: Cascading Style Sheets, used to style web documents.

Domain: A human-readable address used to access a website.

Element: A component of an HTML document.

Flexbox: A one-dimensional CSS layout system.

Front End: The user-facing part of a website.

HTML: HyperText Markup Language, used to structure web content.

HTTP: Hypertext Transfer Protocol, used for communication between web clients and servers.

Hyperlink: A connection to another page or resource.

JavaScript: A programming language commonly used to add interactivity to websites.

Media Query: A CSS feature that applies styles under specified conditions.

Responsive Design: An approach that adapts layouts to different devices.

Selector: A CSS pattern used to identify elements for styling.

Semantic HTML: HTML that uses meaningful elements to describe content.

Server: A computer or software system that provides resources or services to clients.

Tag: Markup written inside angle brackets to define an HTML element.

URL: Uniform Resource Locator, the address of a resource on the web.
