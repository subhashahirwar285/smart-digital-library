Chapter 1: Introduction to Java

1.1 What is Java?

Java is a high-level, class-based, general-purpose programming language. It was developed by James Gosling and his team at Sun Microsystems and was officially released in 1995. Java was designed to make software development portable, reliable and suitable for a wide range of computing environments.

A programming language allows developers to write instructions that a computer can execute. Java programs are generally compiled into bytecode, which can be executed by a compatible Java Virtual Machine.

1.2 History of Java

Java began as a project called Green at Sun Microsystems. It was initially designed for electronic devices and later developed into a general-purpose language for networked computing. The language became popular because of its portability and object-oriented programming model. Oracle acquired Sun Microsystems in 2010 and now leads the development of Oracle's Java platform, while OpenJDK provides the open-source reference implementation.

1.3 Features of Java

  • Simple: Java has a structured syntax influenced by C and C++.
  • Object-Oriented: It supports classes, objects, inheritance and polymorphism.
  • Platform Independent: Java bytecode can execute on compatible JVM implementations.
  • Secure: Java includes runtime checks, type safety and security mechanisms.
  • Robust: Exception handling and automatic memory management help build reliable software.
  • Multithreaded: Java supports concurrent execution using threads.
  • Portable: Programs can be moved between compatible platforms.
  • High Performance: Just-in-time compilation can improve execution speed.

1.4 Java Platform Components

The Java platform provides tools and runtime components for developing and executing Java applications.

  • JDK: Java Development Kit. It contains tools used to develop, compile and debug programs.
  • JRE: Java Runtime Environment. It describes the runtime components required to execute Java applications.
  • JVM: Java Virtual Machine. It loads and executes Java bytecode.

1.5 Applications of Java

Java is used in banking systems, enterprise applications, server-side software, web services, desktop applications, scientific tools and many other areas. It is also widely used in educational programming and software development projects.

Important: Java is both a programming language and part of a larger software platform. The JVM is a major reason Java programs can run on different operating systems.

1.6 Advantages and Limitations

Java offers portability, a large ecosystem, strong typing and automatic memory management. However, it may require more code than some scripting languages, and its runtime memory requirements may be higher for small applications.

Chapter 2: Java Environment and First Program

2.1 Java Development Environment

A development environment contains the software tools required to create and run Java programs. The most important requirement is a suitable JDK. A programmer also needs a code editor or an Integrated Development Environment.

Popular development environments include IntelliJ IDEA, Eclipse and Visual Studio Code with appropriate Java extensions.

2.2 Installing and Checking Java

Install a suitable JDK and configure the system PATH if required. Open a terminal and check the installed Java runtime and compiler:

java -version
javac -version

The java command launches Java applications, while javac compiles Java source files.

2.3 Structure of a Java Program

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

2.4 Explanation of the Program

  • public: An access modifier that makes the class accessible according to Java visibility rules.
  • class: A keyword used to declare a class.
  • Main: The class name. The public class name must match the source filename.
  • main(): The standard entry point for launching this application.
  • String[] args: An array that receives command-line arguments.
  • System.out.println(): Displays output followed by a new line.

2.5 Compilation and Execution

Save the source file as Main.java. Open the terminal in the same folder and execute:

javac Main.java
java Main
Hello, World!

The compiler generates a Main.class file containing bytecode. The Java launcher starts the class through the JVM.

2.6 Comments in Java

Comments provide explanations for programmers and are not executed as program instructions.

// Single-line comment

/*
   Multi-line comment
*/

/**
 * Documentation comment
 */

2.7 Input Using Scanner

The Scanner class can read user input from the keyboard. It belongs to the java.util package.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = input.nextLine();

        System.out.println("Welcome " + name);
        input.close();
    }
}

Chapter 3: Variables and Data Types

3.1 Variables

A variable is a named reference to a value stored during program execution. Every variable has a data type that determines the kind of value it can hold and the operations that can be performed on it.

int age = 20;
double price = 99.50;
char grade = 'A';
boolean active = true;
String name = "Rahul";

3.2 Rules for Naming Variables

  • A name may contain letters, digits, underscores and dollar signs.
  • A name cannot begin with a digit.
  • Java keywords cannot be used as variable names.
  • Names are case-sensitive.
  • Descriptive names improve readability.

3.3 Primitive Data Types

Java provides eight primitive data types:

  • byte: An 8-bit signed integer.
  • short: A 16-bit signed integer.
  • int: A 32-bit signed integer.
  • long: A 64-bit signed integer.
  • float: A 32-bit floating-point number.
  • double: A 64-bit floating-point number.
  • char: A 16-bit UTF-16 code unit.
  • boolean: Represents true or false.

3.4 Reference Data Types

Reference types refer to objects. Examples include classes, arrays, interfaces and enumerations. String is a commonly used reference type.

3.5 Constants Using final

The final keyword prevents a variable from being reassigned after it has been initialized.

final double PI = 3.14159;
System.out.println(PI);

3.6 Type Casting

Type conversion changes a value from one data type to another. Widening conversions are generally automatic when the target type can represent the source type. Narrowing conversions require an explicit cast and may lose information.

int number = 25;
double result = number;

double value = 19.75;
int wholeNumber = (int) value;

System.out.println(result);
System.out.println(wholeNumber);
25.0
19

3.7 Variable Scope

Scope determines where a variable can be accessed. Local variables are declared inside methods or blocks. Instance variables belong to objects, while static variables belong to the class itself.

Chapter 4: Operators and Expressions

4.1 Introduction to Operators

Operators are symbols that perform operations on values and variables. An expression combines operands and operators to produce a result.

4.2 Arithmetic Operators

Arithmetic operators perform mathematical calculations. They include addition (+), subtraction (-), multiplication (*), division (/) and remainder (%).

int a = 20;
int b = 6;

System.out.println(a + b);
System.out.println(a - b);
System.out.println(a * b);
System.out.println(a / b);
System.out.println(a % b);

When both operands are integers, division produces an integer result. Use a floating-point operand when a decimal result is required.

4.3 Relational Operators

Relational operators compare two values and return a boolean result. Examples include ==, !=, >, <, >= and <=.

int x = 10;
int y = 20;

System.out.println(x == y);
System.out.println(x < y);
System.out.println(x != y);

4.4 Logical Operators

Logical operators combine Boolean expressions. The && operator means logical AND, || means logical OR, and ! reverses a Boolean value. The && and || operators use short-circuit evaluation.

int age = 20;
boolean hasID = true;

System.out.println(age >= 18 && hasID);
System.out.println(age < 18 || hasID);
System.out.println(!hasID);

4.5 Assignment Operators

Assignment operators store values or update an existing variable. Common examples are =, +=, -=, *=, /= and %=.

int number = 10;
number += 5;
number *= 2;
System.out.println(number);

4.6 Increment and Decrement

The ++ operator increases a variable by one, while -- decreases it by one. Prefix and postfix forms differ in when the updated value is used in an expression.

int a = 5;
System.out.println(++a);

int b = 5;
System.out.println(b++);

4.7 Conditional Operator

The conditional operator ?: provides a compact way to select one of two values based on a condition.

int marks = 75;
String result = marks >= 40 ? "Pass" : "Fail";
System.out.println(result);

Chapter 5: Conditional Statements and Loops

5.1 Decision Making

Decision-making statements allow a program to select different actions based on conditions. Java provides if, if-else, else-if and switch statements.

5.2 If-Else Statement

int marks = 75;

if (marks >= 40) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}

5.3 Else-If Ladder

An else-if ladder checks multiple conditions in sequence. The first true condition determines the block that executes.

int marks = 82;

if (marks >= 90) {
    System.out.println("Grade A+");
} else if (marks >= 75) {
    System.out.println("Grade A");
} else if (marks >= 60) {
    System.out.println("Grade B");
} else {
    System.out.println("Needs Improvement");
}

5.4 Switch Statement

A switch statement selects a branch based on the value of an expression. The break statement prevents execution from falling through into subsequent cases in the traditional switch form.

int day = 2;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Other day");
}

5.5 For Loop

A for loop is useful when the number of repetitions is known or controlled by an initialization, condition and update expression.

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

5.6 While Loop

A while loop checks its condition before each iteration. It is useful when the number of repetitions depends on a condition.

int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}

5.7 Do-While Loop

A do-while loop executes its body at least once because the condition is checked after the body.

int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);

5.8 Break and Continue

The break statement terminates the nearest loop or switch. The continue statement skips the remaining statements in the current loop iteration.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    System.out.println(i);
}

5.9 Nested Loops

A nested loop is a loop inside another loop. It is commonly used for tables, matrices and pattern printing.

for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 3; col++) {
        System.out.print("* ");
    }
    System.out.println();
}

Chapter 6: Arrays and Strings

6.1 Introduction to Arrays

An array is a fixed-size data structure that stores multiple values of the same declared element type. Each element is accessed through an index, starting from zero. The length of an array is available through its length field.

int[] marks = {75, 80, 90, 85};

System.out.println(marks[0]);
System.out.println(marks.length);

6.2 Creating an Array

int[] numbers = new int[5];

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;

System.out.println(numbers[1]);

6.3 Traversing an Array

Array elements can be processed using a for loop or an enhanced for loop.

int[] values = {10, 20, 30, 40};

for (int value : values) {
    System.out.println(value);
}

6.4 Two-Dimensional Arrays

A two-dimensional array is an array whose elements are themselves arrays. It is useful for representing rows and columns, such as a matrix.

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

System.out.println(matrix[1][2]);

6.5 Searching an Array

Linear search checks each element until the target is found or the array ends. It works on both sorted and unsorted arrays.

int[] numbers = {5, 10, 15, 20};
int target = 15;
int position = -1;

for (int i = 0; i < numbers.length; i++) {
    if (numbers[i] == target) {
        position = i;
        break;
    }
}

System.out.println(position);

6.6 Introduction to Strings

A String represents a sequence of characters. String objects are immutable, meaning their contents cannot be changed after creation. Operations that appear to modify a String create another String value.

String name = "Java Programming";

System.out.println(name.length());
System.out.println(name.toUpperCase());
System.out.println(name.toLowerCase());
System.out.println(name.charAt(0));
System.out.println(name.substring(0, 4));

6.7 String Comparison

Use equals() to compare String contents. The == operator compares object references rather than text contents.

String first = "Java";
String second = new String("Java");

System.out.println(first.equals(second));
System.out.println(first == second);

6.8 StringBuilder

StringBuilder is useful when a program needs to modify text repeatedly. Unlike String, its contents can be changed without creating a new String object for every operation.

StringBuilder text = new StringBuilder("Java");
text.append(" Programming");
System.out.println(text);

Chapter 7: Classes and Objects

7.1 Object-Oriented Programming

Object-Oriented Programming is a programming approach that organizes software around objects. An object combines state, represented by fields, and behavior, represented by methods. OOP helps divide large applications into manageable components.

7.2 What is a Class?

A class is a blueprint that describes the fields and methods its objects can have. It defines the structure and behavior of a particular type of object.

7.3 What is an Object?

An object is an instance of a class. Different objects created from the same class can hold different values in their instance fields.

7.4 Creating a Class and Object

class Student {
    String name;
    int age;

    void display() {
        System.out.println(name);
        System.out.println(age);
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Aman";
        student.age = 20;

        student.display();
    }
}
Aman

7.5 Fields and Methods

Fields represent the data associated with an object. Methods define the operations an object can perform. A method may accept parameters and return a result.

7.6 The this Keyword

The this keyword refers to the current object. It is often used when a parameter has the same name as an instance field.

class Student {
    String name;

    Student(String name) {
        this.name = name;
    }
}

7.7 Static Members

A static field or method belongs to the class rather than to a particular object. Static members are commonly accessed using the class name.

class Counter {
    static int count = 0;

    Counter() {
        count++;
    }
}

public class Main {
    public static void main(String[] args) {
        new Counter();
        new Counter();
        System.out.println(Counter.count);
    }
}

Chapter 8: Constructors, Methods and Keywords

8.1 Constructors

A constructor initializes an object when it is created. It has the same name as its class and does not declare a return type. If no constructor is written, Java may provide a default constructor under the language rules.

8.2 No-Argument Constructor

class Book {
    String title;

    Book() {
        title = "Java Programming";
    }

    void display() {
        System.out.println(title);
    }
}

8.3 Parameterized Constructor

A parameterized constructor accepts values so an object can be initialized with specific data.

class Book {
    String title;
    String author;

    Book(String title, String author) {
        this.title = title;
        this.author = author;
    }

    void display() {
        System.out.println(title);
        System.out.println(author);
    }
}

8.4 Constructor Overloading

A class can define multiple constructors with different parameter lists. This allows objects to be initialized in different ways.

class Box {
    int length;
    int width;

    Box() {
        length = 1;
        width = 1;
    }

    Box(int length, int width) {
        this.length = length;
        this.width = width;
    }
}

8.5 Method Overloading

Method overloading allows multiple methods to share a name when their parameter lists differ. The compiler determines which method to call based on the arguments.

class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }
}

8.6 The final Keyword

The final keyword can restrict reassignment of variables, overriding of methods and inheritance from classes, depending on where it is used.

8.7 The this and super Keywords

this refers to the current object. super refers to the superclass portion of the current object and can be used to access superclass constructors and members where permitted.

Chapter 9: Inheritance

9.1 Introduction

Inheritance is an OOP mechanism in which a class derives accessible fields and methods from another class. The existing class is called the superclass, while the derived class is called the subclass. Inheritance supports code reuse and allows related classes to share common behavior.

9.2 Single Inheritance

Single inheritance occurs when one subclass extends one superclass.

class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat();
        dog.bark();
    }
}

9.3 Multilevel Inheritance

In multilevel inheritance, a class extends another subclass, creating a chain of inheritance.

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

class Puppy extends Dog {
    void play() {
        System.out.println("Playing");
    }
}

9.4 Hierarchical Inheritance

Hierarchical inheritance occurs when multiple subclasses extend the same superclass. Each subclass can add its own specialized behavior.

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

class Cat extends Animal {
    void meow() {
        System.out.println("Meowing");
    }
}

9.5 Multiple Inheritance

Java does not allow a class to extend multiple classes. This avoids certain ambiguities in class inheritance. A class can, however, implement multiple interfaces to obtain multiple type contracts.

9.6 Method Overriding

A subclass can provide a new implementation of an inherited instance method. This is known as method overriding. The @Override annotation helps the compiler verify that the method actually overrides a superclass method.

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Cat extends Animal {
    @Override
    void sound() {
        System.out.println("Meow");
    }
}

9.7 Advantages of Inheritance

  • Encourages code reuse.
  • Supports class hierarchies.
  • Allows specialized behavior in subclasses.
  • Works with runtime polymorphism.

Chapter 10: Polymorphism

10.1 Meaning of Polymorphism

Polymorphism means many forms. In object-oriented programming, it allows a common method name or reference type to work with different forms of behavior. It helps build flexible and extensible programs.

10.2 Compile-Time Polymorphism

Method overloading is commonly described as compile-time polymorphism. Multiple methods share the same name but have different parameter lists.

class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator c = new Calculator();

        System.out.println(c.add(10, 20));
        System.out.println(c.add(5.5, 2.5));
    }
}

10.3 Runtime Polymorphism

Runtime polymorphism occurs when an overridden instance method is selected based on the actual object at runtime. A superclass reference can refer to a subclass object.

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal animal = new Dog();
        animal.sound();
    }
}
Dog barks

10.4 Dynamic Method Dispatch

Dynamic method dispatch is the process by which Java selects an overridden instance method at runtime based on the actual object. It is a key mechanism behind runtime polymorphism.

10.5 Benefits of Polymorphism

  • Allows common interfaces for different objects.
  • Reduces dependence on specific implementation classes.
  • Supports extensible software design.
  • Makes code easier to maintain when new implementations are added.

10.6 Overloading and Overriding

Overloading uses the same method name with different parameter lists. Overriding provides a subclass implementation of an inherited method with a compatible signature.

Chapter 11: Abstraction and Interfaces

11.1 Abstraction

Abstraction focuses on essential behavior while hiding unnecessary implementation details. It allows a programmer to work with what an object does without needing to know every detail of how it performs the task.

11.2 Abstract Classes

An abstract class is declared using the abstract keyword. It cannot be instantiated directly and may contain abstract methods as well as fully implemented methods.

abstract class Shape {
    abstract void draw();

    void message() {
        System.out.println("Shape example");
    }
}

class Circle extends Shape {
    @Override
    void draw() {
        System.out.println("Drawing Circle");
    }
}

public class Main {
    public static void main(String[] args) {
        Shape shape = new Circle();
        shape.draw();
        shape.message();
    }
}

11.3 Interfaces

An interface defines a contract that implementing classes agree to follow. Interfaces can contain abstract methods, constants, default methods, static methods and private helper methods, depending on the Java version.

interface Printable {
    void print();
}

class Document implements Printable {
    public void print() {
        System.out.println("Printing document");
    }
}

public class Main {
    public static void main(String[] args) {
        Printable item = new Document();
        item.print();
    }
}

11.4 Multiple Interfaces

A class can implement more than one interface. This allows it to follow several independent contracts without inheriting from multiple classes.

interface Printable {
    void print();
}

interface Scannable {
    void scan();
}

class Machine implements Printable, Scannable {
    public void print() {
        System.out.println("Printing");
    }

    public void scan() {
        System.out.println("Scanning");
    }
}

11.5 Encapsulation

Encapsulation combines data and related methods inside a class while controlling access to internal state. Private fields and public methods are commonly used to protect data from uncontrolled modification.

class BankAccount {
    private double balance;

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public double getBalance() {
        return balance;
    }
}

11.6 Abstraction and Encapsulation

Abstraction focuses on exposing essential features and hiding implementation complexity. Encapsulation focuses on bundling state and behavior while controlling access to the internal data. Both concepts help create maintainable software.

Chapter 12: Packages and Access Modifiers

12.1 What is a Package?

A package is a namespace used to organize related Java classes and interfaces. Packages help prevent naming conflicts, improve code organization and control access.

12.2 Built-in Packages

  • java.lang: Fundamental language classes. It is imported automatically.
  • java.util: Collections, Scanner and utility classes.
  • java.io: Input and output operations.
  • java.net: Networking classes.
  • java.sql: Database connectivity interfaces and classes.

12.3 Importing a Package

import java.util.Scanner;
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList names = new ArrayList<>();
        names.add("Aman");
        System.out.println(names);
    }
}

12.4 Creating a User-Defined Package

A programmer can create a package by placing a package declaration at the beginning of a source file. The directory structure should match the package name when compiling and organizing the classes.

package mylibrary;

public class Book {
    public void display() {
        System.out.println("Java Book");
    }
}

12.5 Access Modifiers

  • public: Accessible from any location where the declaring type is visible.
  • private: Accessible only within the declaring top-level class or enclosing context allowed by Java.
  • protected: Accessible within the same package and by subclasses under Java access rules.
  • Default: When no access modifier is written, access is limited to the same package.

12.6 Benefits of Packages

Packages group related code, make large projects easier to navigate, reduce class-name conflicts and support controlled access between components.

Chapter 13: Exception Handling

13.1 What is an Exception?

An exception is an event that interrupts the normal flow of a program. Java represents exceptions as objects. Exception handling allows a program to respond to expected error conditions rather than terminating without a useful response.

13.2 Types of Problems

  • Checked Exceptions: Checked by the compiler, such as IOException.
  • Unchecked Exceptions: Runtime exceptions, such as ArithmeticException and NullPointerException.
  • Errors: Serious problems that applications generally do not handle as ordinary exceptions.

13.3 try and catch

The try block contains statements that may throw an exception. A matching catch block handles the exception.

public class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }
    }
}
Cannot divide by zero

13.4 Multiple Catch Blocks

A try block can be followed by multiple catch blocks to handle different exception types. More specific exception types should appear before broader types.

try {
    int[] numbers = {10, 20};
    System.out.println(numbers[5]);
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Invalid array index");
} catch (Exception e) {
    System.out.println("An error occurred");
}

13.5 Finally Block

The finally block is generally used for cleanup operations. It normally executes whether or not an exception occurs, although there are exceptional circumstances such as abrupt JVM termination.

try {
    System.out.println("Inside try");
} catch (Exception e) {
    System.out.println("Error occurred");
} finally {
    System.out.println("Cleanup completed");
}

13.6 throw and throws

The throw keyword explicitly throws an exception object. The throws keyword declares that a method may pass certain exceptions to its caller.

public class Main {
    static void checkAge(int age) {
        if (age < 18) {
            throw new IllegalArgumentException("Age below 18");
        }

        System.out.println("Eligible");
    }

    public static void main(String[] args) {
        checkAge(20);
    }
}

13.7 Custom Exceptions

A programmer can create a custom exception class to represent an application-specific error condition.

class InvalidMarksException extends Exception {
    InvalidMarksException(String message) {
        super(message);
    }
}

13.8 Benefits of Exception Handling

  • Separates error-handling logic from normal program logic.
  • Improves reliability.
  • Allows meaningful error messages.
  • Supports cleanup of resources.

Chapter 14: Multithreading

14.1 Introduction to Threads

A thread is a path of execution within a process. Multithreading allows multiple threads to make progress within one application. It is useful for responsive interfaces, background tasks and concurrent processing.

14.2 Process and Thread

A process is an executing program with its own resources. Threads exist within a process and generally share the process's memory. Each thread has its own execution stack and program state.

14.3 Creating a Thread by Extending Thread

class MyThread extends Thread {
    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.start();
    }
}

The start() method asks the JVM to schedule a new thread. The thread executes its run() method. Calling run() directly is an ordinary method call and does not start a new thread.

14.4 Creating a Thread Using Runnable

The Runnable interface represents a task that can be executed by a thread. It is often preferred because the class remains free to extend another class.

class MyTask implements Runnable {
    public void run() {
        System.out.println("Task is running");
    }
}

public class Main {
    public static void main(String[] args) {
        Thread t = new Thread(new MyTask());
        t.start();
    }
}

14.5 Thread Life Cycle

Java defines thread states such as NEW, RUNNABLE, BLOCKED, WAITING, TIMED_WAITING and TERMINATED. A thread moves between states as it is started, scheduled, waits for resources or finishes execution.

14.6 Thread Methods

  • start(): Starts a new thread.
  • run(): Contains the task executed by the thread.
  • sleep(): Temporarily pauses the current thread.
  • join(): Waits for another thread to finish.
  • isAlive(): Checks whether a thread has been started and has not terminated.

14.7 Synchronization

When multiple threads access shared mutable data, their operations can interfere with one another. Synchronization provides controlled access to critical sections and helps prevent certain race conditions.

class Counter {
    private int count = 0;

    public synchronized void increment() {
        count++;
    }

    public int getCount() {
        return count;
    }
}

14.8 Applications of Multithreading

Multithreading is used in servers, background file processing, user interfaces, simulations and applications that perform multiple tasks concurrently.

Chapter 15: Collections and File Handling

15.1 Java Collections Framework

The Java Collections Framework provides interfaces and classes for storing, retrieving and processing groups of objects. It reduces the need to create common data structures from scratch.

15.2 List Interface

A List is an ordered collection that allows duplicate elements. ArrayList and LinkedList are commonly used List implementations.

import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList names = new ArrayList<>();

        names.add("Aman");
        names.add("Ravi");
        names.add("Priya");

        for (String name : names) {
            System.out.println(name);
        }
    }
}

15.3 Set Interface

A Set represents a collection that does not contain duplicate elements. HashSet is a common implementation and does not guarantee a particular iteration order.

import java.util.HashSet;

public class Main {
    public static void main(String[] args) {
        HashSet numbers = new HashSet<>();

        numbers.add(10);
        numbers.add(20);
        numbers.add(10);

        System.out.println(numbers);
    }
}

15.4 Map Interface

A Map stores key-value associations. Keys are unique, and each key maps to at most one value. HashMap is a commonly used implementation.

import java.util.HashMap;

public class Main {
    public static void main(String[] args) {
        HashMap students = new HashMap<>();

        students.put(1, "Aman");
        students.put(2, "Ravi");

        System.out.println(students.get(1));
    }
}

15.5 Generics

Generics allow classes, interfaces and methods to work with specified types. They improve type safety and reduce the need for explicit casting.

ArrayList names = new ArrayList<>();
names.add("Java");

15.6 Introduction to File Handling

File handling allows a program to store information permanently and retrieve it later. Java provides classes such as File, FileReader, FileWriter, BufferedReader and BufferedWriter.

15.7 Writing to a File

import java.io.FileWriter;
import java.io.IOException;

public class Main {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("notes.txt")) {
            writer.write("Welcome to Java File Handling");
            System.out.println("File written successfully");
        } catch (IOException e) {
            System.out.println("Unable to write file");
        }
    }

15.8 Reading a File

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) {
        try (BufferedReader reader =
                 new BufferedReader(new FileReader("notes.txt"))) {

            String line;

            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }

        } catch (IOException e) {
            System.out.println("Unable to read file");
        }
    }
}

Chapter 16: JDBC and Database Connectivity

16.1 Introduction to JDBC

JDBC stands for Java Database Connectivity. It is a Java API that allows applications to connect to databases, send SQL statements and process query results. JDBC provides a common programming interface while database drivers handle database-specific communication.

16.2 JDBC Architecture

A typical JDBC application contains a Java application, JDBC API, a database driver and a database server. The application uses JDBC interfaces such as Connection, PreparedStatement and ResultSet to interact with the database.

16.3 Important JDBC Components

  • DriverManager: Helps establish database connections through registered drivers.
  • Connection: Represents a connection to a database.
  • Statement: Executes SQL statements.
  • PreparedStatement: Executes parameterized SQL statements.
  • ResultSet: Represents data returned by a query.

16.4 Steps to Connect a Database

  1. Install and configure a database system.
  2. Add the correct JDBC driver to the project.
  3. Prepare the database URL and credentials.
  4. Establish a connection.
  5. Execute SQL statements.
  6. Process the results.
  7. Close database resources.

16.5 Example: JDBC Connection

The following example uses a MySQL JDBC driver. The driver dependency must be included in the project, and the database must exist.

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class Main {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/library";
        String user = "root";
        String password = "your_password";

        try (Connection connection =
                 DriverManager.getConnection(url, user, password)) {

            System.out.println("Database connected");

        } catch (SQLException e) {
            System.out.println("Database connection failed");
        }
    }
}

16.6 PreparedStatement

PreparedStatement is used for parameterized SQL statements. It helps separate SQL structure from supplied values and is the preferred approach for user-provided input.

String sql = "INSERT INTO students(name, course) VALUES (?, ?)";

try (PreparedStatement statement =
         connection.prepareStatement(sql)) {

    statement.setString(1, "Aman");
    statement.setString(2, "BCA");

    int rows = statement.executeUpdate();
    System.out.println(rows + " row inserted");
}

16.7 ResultSet

ResultSet represents rows returned by a query. Its next() method moves the cursor to the next available row.

String sql = "SELECT id, name FROM students";

try (PreparedStatement statement =
         connection.prepareStatement(sql);
     ResultSet result = statement.executeQuery()) {

    while (result.next()) {
        System.out.println(result.getInt("id"));
        System.out.println(result.getString("name"));
    }
}

16.8 Database Transactions

A transaction groups database operations into a unit of work. Transactions can be committed when successful or rolled back when an operation fails. This helps preserve data consistency.

Never store real database passwords directly in source code in a production application. Use secure configuration and suitable access controls.

Chapter 17: Practical Mini Projects

17.1 Importance of Projects

Projects allow students to apply programming concepts to practical problems. A project combines variables, control statements, methods, classes, collections and sometimes file or database operations.

17.2 Project: Simple Calculator

This program accepts two numbers and performs a selected arithmetic operation.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("First number: ");
        double a = input.nextDouble();

        System.out.print("Second number: ");
        double b = input.nextDouble();

        System.out.println("1. Addition");
        System.out.println("2. Subtraction");
        System.out.println("3. Multiplication");
        System.out.println("4. Division");

        int choice = input.nextInt();

        switch (choice) {
            case 1:
                System.out.println(a + b);
                break;
            case 2:
                System.out.println(a - b);
                break;
            case 3:
                System.out.println(a * b);
                break;
            case 4:
                if (b != 0) {
                    System.out.println(a / b);
                } else {
                    System.out.println("Cannot divide by zero");
                }
                break;
            default:
                System.out.println("Invalid choice");
        }

        input.close();
    }
}

Glossary

  • Abstraction: Exposing essential behavior while hiding implementation details.
  • Array: A fixed-size sequence of elements of the same declared type.
  • Bytecode: Intermediate code produced by the Java compiler.
  • Class: A blueprint for creating objects.
  • Collection: An object that groups multiple elements.
  • Constructor: A special member used to initialize a new object.
  • Encapsulation: Bundling state and behavior while controlling access.
  • Exception: An event that disrupts normal program execution.
  • Inheritance: A mechanism for deriving a class from another class.
  • Interface: A Java type that defines a contract for implementing classes.
  • JDK: Java Development Kit.
  • JDBC: Java Database Connectivity.
  • JRE: Java Runtime Environment.
  • JVM: Java Virtual Machine.
  • Method: A block of code that performs a task.
  • Object: An instance of a class.
  • Package: A namespace used to organize Java types.
  • Polymorphism: The ability to represent different forms of behavior.
  • Thread: A path of execution within a process.
  • Variable: A named storage location or reference to a value.
