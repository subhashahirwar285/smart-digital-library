Chapter 1: Introduction to Python

1.1 What is Python?

Python is a high-level, general-purpose programming language. It was created by Guido van Rossum and first released in 1991. Python focuses on readable syntax and allows programmers to write clear instructions for computers.

Python supports procedural, object-oriented and functional programming styles. It is used by beginners, researchers and professional software developers.

1.2 Features of Python

  • Easy to Learn: Its syntax is readable and beginner-friendly.
  • Interpreted: Python programs are executed by a Python implementation.
  • Portable: Python is available for different operating systems.
  • Open Source: It is freely available to use and distribute.
  • Large Library: It provides modules for many programming tasks.
  • Object-Oriented: It supports classes and objects.
  • Dynamic Typing: Variable types are determined at runtime.

1.3 Applications of Python

Python is used in web development, automation, data science, artificial intelligence, machine learning, scientific research, testing and desktop software.

1.4 Python Programming Paradigms

A programming paradigm is a style of organizing and writing programs.

  • Procedural: Programs are organized as sequences of instructions and functions.
  • Object-Oriented: Programs are organized using classes and objects.
  • Functional: Programs use functions and expressions to process data.

1.5 Advantages and Limitations

Python offers rapid development, readable code and a large ecosystem. However, some Python programs may execute more slowly than equivalent programs written in compiled languages, and memory use can be higher for certain workloads.

Chapter 2: Python Environment and First Program

2.1 Installing Python

Python can be installed on Windows, Linux and macOS. Download the installer from the official Python website. On Windows, enable the option to add Python to PATH during installation.

2.2 Checking Installation

Open a terminal or command prompt and enter:

python --version

The command displays the installed Python version when Python is correctly configured.

2.3 Python Interpreter

The Python interpreter executes Python instructions. It can run a saved Python file or accept commands interactively.

2.4 First Python Program

print("Hello, World!")

The print() function displays information on the screen. Text values are placed inside quotation marks.

2.5 Comments

Comments explain code and are ignored during normal execution.

# This is a single-line comment
print("Welcome to Python")

2.6 Taking User Input

The input() function accepts information entered by a user. It returns the entered value as a string.

name = input("Enter your name: ")
print("Welcome", name)

2.7 Displaying Output

name = "Aman"
age = 20
print("Name:", name)
print("Age:", age)
Remember: input() returns text. Convert it using int() or float() when numeric calculations are required.

Chapter 3: Variables and Data Types

3.1 Variables

A variable is a name that refers to a value in a program. Python creates a variable when a value is assigned to it.

name = "Rahul"
age = 20
marks = 85.5

print(name)
print(age)
print(marks)

3.2 Rules for Naming Variables

  • A variable name must begin with a letter or underscore.
  • It cannot begin with a number.
  • Spaces are not allowed.
  • Variable names are case-sensitive.
  • Python keywords cannot be used as variable names.

3.3 Basic Data Types

  • int: Whole numbers such as 10 and 25.
  • float: Decimal numbers such as 12.5.
  • str: Text such as "Python".
  • bool: Boolean values True and False.
  • list: An ordered, mutable collection.
  • tuple: An ordered, immutable collection.
  • dict: A collection of key-value pairs.
  • set: A collection of unique elements.

3.4 Checking Data Types

name = "Aman"
age = 21
price = 99.50
active = True

print(type(name))
print(type(age))
print(type(price))
print(type(active))

3.5 Type Conversion

Type conversion changes a value from one data type to another when the conversion is valid.

age = "20"
age = int(age)
print(age + 5)

3.6 Multiple Assignment

x, y, z = 10, 20, 30
print(x, y, z)

Chapter 4: Operators and Expressions

4.1 Introduction

Operators are symbols or keywords that perform operations on values and variables. An expression combines values, variables and operators to produce a result.

4.2 Arithmetic Operators

Python provides addition (+), subtraction (-), multiplication (*), division (/), floor division (//), modulus (%) and exponentiation (**).

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)

4.3 Comparison Operators

Comparison operators compare two values and return True or False. Examples include ==, !=, >, <, >= and <=.

x = 10
y = 20

print(x == y)
print(x < y)
print(x != y)

4.4 Logical Operators

The logical operators are and, or and not. They combine or reverse Boolean conditions.

age = 20

print(age >= 18 and age <= 60)
print(age < 18 or age > 60)
print(not age < 18)

4.5 Assignment Operators

Assignment operators store or update values. Examples include =, +=, -=, *= and /=.

number = 10
number += 5
print(number)

4.6 Membership Operators

The in and not in operators check whether a value is present in a sequence or collection.

languages = ["Python", "Java", "C"]

print("Python" in languages)
print("PHP" not in languages)

4.7 Operator Precedence

Operator precedence determines the order in which parts of an expression are evaluated. Parentheses can be used to make the intended order clear.

Chapter 5: Conditional Statements

5.1 Introduction

Conditional statements allow a program to make decisions. Python uses if, elif and else to execute different blocks depending on conditions.

5.2 The if Statement

age = 20

if age >= 18:
print("Eligible by age condition")

5.3 The if-else Statement

number = 7

if number % 2 == 0:
print("Even number")
else:
print("Odd number")

5.4 The if-elif-else Statement

marks = 75

if marks >= 80:
print("Grade A")
elif marks >= 60:
print("Grade B")
elif marks >= 40:
print("Grade C")
else:
print("Needs Improvement")

5.5 Nested if Statement

A nested if statement is an if statement placed inside another conditional block.

number = 15

if number > 0:
if number % 5 == 0:
print("Positive and divisible by 5")
else:
print("Positive but not divisible by 5")
else:
print("Not positive")

5.6 Practical Example: Largest of Two Numbers

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

if a > b:
print("First number is larger")
elif b > a:
print("Second number is larger")
else:
print("Both numbers are equal")
Python uses indentation to define blocks. Keep indentation consistent, normally using four spaces.

Chapter 6: Loops and Iterations

6.1 Introduction to Loops

A loop repeats a block of code. Loops reduce repeated instructions and are useful for processing collections and performing calculations.

6.2 The for Loop

A for loop repeats a block for each item in a sequence or iterable.

for number in range(1, 6):
    print(number)

6.3 The range() Function

The range() function generates a sequence of integers. It is commonly used with for loops.

for number in range(2, 11, 2):
    print(number)

6.4 The while Loop

A while loop repeats while its condition remains True. The condition should eventually become False to avoid an unintended infinite loop.

count = 1

while count <= 5:
print(count)
count += 1

6.5 break Statement

The break statement terminates the nearest enclosing loop.

for number in range(1, 6):
if number == 3:
break
print(number)

6.6 continue Statement

The continue statement skips the remaining statements in the current iteration and proceeds to the next iteration.

for number in range(1, 6):
if number == 3:
continue
print(number)

6.7 Nested Loops

A nested loop is a loop placed inside another loop. It is useful for patterns, tables and two-dimensional data.

for row in range(1, 4):
for column in range(1, 4):
print("*", end=" ")
print()

6.8 Sum of Numbers

total = 0

for number in range(1, 6):
total += number

print("Sum:", total)

  2. Differentiate for and while loops.

Chapter 7: Functions and Modules

7.1 What is a Function?

A function is a reusable block of code designed to perform a particular task. Functions improve organization, reduce repetition and make programs easier to maintain.

7.2 Defining a Function

Python uses the def keyword to define a function.

def greet():
    print("Welcome to Python")

greet()

7.3 Parameters and Arguments

Parameters are names written in a function definition. Arguments are the actual values passed when the function is called.

def add(a, b):
print(a + b)

add(10, 20)

7.4 Return Statement

The return statement sends a result back to the caller.

def square(number):
return number * number

result = square(5)
print(result)

7.5 Default Arguments

def greet(name="Student"):
print("Hello", name)

greet()
greet("Aman")

7.6 Keyword Arguments

def student(name, course):
print(name, course)

student(course="BCA", name="Aman")

7.7 Variable Scope

A local variable is created inside a function and is normally accessible within that function. A global variable is defined outside functions and can be accessed from broader program scope.

college = "Oriental University"

def show():
course = "BCA"
print(college)
print(course)

show()

7.8 Lambda Functions

A lambda expression creates a small anonymous function.

square = lambda x: x * x
print(square(5))

7.9 Modules

A module is a Python file containing reusable code such as functions and variables. It can be imported into another program.

import math

print(math.sqrt(25))
print(math.pi)

Chapter 8: Lists, Tuples, Sets and Dictionaries

8.1 Lists

A list is an ordered and mutable collection. It can contain values of different data types and allows duplicate elements.

fruits = ["Apple", "Mango", "Banana"]

print(fruits[0])
fruits.append("Orange")
print(fruits)

Common list methods include append(), insert(), remove(), pop(), sort() and reverse().

8.2 List Slicing

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
print(numbers[:3])
print(numbers[-2:])

8.3 List Comprehension

List comprehension provides a compact way to create a list from an iterable.

squares = [number * number for number in range(1, 6)]
print(squares)

8.4 Tuples

A tuple is an ordered collection that cannot be modified after creation.

colors = ("Red", "Green", "Blue")

print(colors[1])
print(len(colors))

8.5 Sets

A set is an unordered collection of unique elements. Duplicate values are removed automatically.

numbers = {1, 2, 2, 3, 4}

print(numbers)
numbers.add(5)
numbers.discard(2)
print(numbers)

8.6 Set Operations

a = {1, 2, 3}
b = {3, 4, 5}

print(a.union(b))
print(a.intersection(b))
print(a.difference(b))

8.7 Dictionaries

A dictionary stores data as key-value pairs. Keys are unique and are used to access their associated values.

student = {
"name": "Aman",
"age": 20,
"course": "BCA"
}

print(student["name"])
student["age"] = 21
print(student)

8.8 Iterating Through a Dictionary

student = {"name": "Aman", "age": 20}

for key, value in student.items():
print(key, value)

8.9 Comparison of Collections

  • Lists are ordered and mutable.
  • Tuples are ordered and immutable.
  • Sets store unique elements.
  • Dictionaries store key-value pairs.

Chapter 9: Strings and String Operations

9.1 What is a String?

A string is a sequence of characters enclosed in single, double or triple quotation marks. Strings are immutable in Python.

message = "Hello Python"

print(message)
print(len(message))
print(message.upper())
print(message.lower())

9.2 String Indexing

Indexing accesses an individual character. Python uses zero-based indexing, meaning the first character has index 0. Negative indexing accesses characters from the end.

word = "Programming"

print(word[0])
print(word[3])
print(word[-1])

9.3 String Slicing

Slicing extracts a portion of a string using a start index, stop index and optional step.

word = "Programming"

print(word[0:4])
print(word[4:8])
print(word[::-1])

9.4 Common String Methods

text = "  Learn Python  "

print(text.strip())
print(text.replace("Python", "Java"))
print(text.find("Python"))
print(text.count("n"))
print(text.startswith("  Learn"))

9.5 Splitting and Joining

sentence = "Python is easy"
words = sentence.split()

print(words)

result = "-".join(words)
print(result)

9.6 String Formatting

Formatted strings make it easier to combine text and values.

name = "Aman"
age = 20

print(f"My name is {name} and I am {age} years old.")

Chapter 10: File Handling

10.1 Introduction

File handling allows a program to create, read, write and manage files. It is useful for storing information permanently so it can be used later.

10.2 Opening a File

The open() function is used to access a file. It accepts a file path and a mode.

file = open("notes.txt", "r")
content = file.read()
print(content)
file.close()

10.3 File Modes

  • r: Read an existing file.
  • w: Write to a file, replacing existing content.
  • a: Append content to a file.
  • x: Create a new file and fail if it already exists.
  • b: Binary mode modifier.

10.4 Writing to a File

with open("notes.txt", "w") as file:
    file.write("Learning Python Programming")

10.5 Reading a File

with open("notes.txt", "r") as file:
    content = file.read()
    print(content)

10.6 Appending Data

with open("notes.txt", "a") as file:
    file.write("\nPython is useful")

10.7 Reading Line by Line

with open("notes.txt", "r") as file:
    for line in file:
        print(line.strip())

10.8 The with Statement

The with statement manages the file context and ensures that the file is properly closed when the block finishes, including when an exception occurs.

Always use appropriate file paths and modes. Writing with mode "w" replaces the existing file content.

Chapter 11: Object-Oriented Programming

11.1 Introduction to OOP

Object-Oriented Programming is a programming approach based on classes and objects. It helps organize programs around data and the operations performed on that data.

11.2 Classes and Objects

A class is a blueprint for creating objects. An object is an instance of a class.

class Student:
    def display(self):
        print("Welcome Student")

student1 = Student()
student1.display()

11.3 Constructor

The **init**() method is commonly used to initialize an object's attributes when it is created.

class Student:
def **init**(self, name, course):
self.name = name
self.course = course

```
def display(self):
    print(self.name, self.course)
```

student = Student("Aman", "BCA")
student.display()

11.4 Instance Attributes and Methods

Instance attributes store information belonging to an object. Instance methods operate on an object and conventionally receive self as their first parameter.

11.5 Inheritance

Inheritance allows a class to derive attributes and methods from another class. It supports code reuse and class relationships.

class Animal:
def speak(self):
print("Animal sound")

class Dog(Animal):
def bark(self):
print("Dog barks")

dog = Dog()
dog.speak()
dog.bark()

11.6 Encapsulation

Encapsulation groups data and related methods within a class. Python uses naming conventions and name mangling to support controlled access patterns.

class Account:
def **init**(self, balance):
self.__balance = balance

```
def show_balance(self):
    print(self.__balance)
```

account = Account(5000)
account.show_balance()

11.7 Polymorphism

Polymorphism allows different objects to respond to the same operation in their own ways.

class Dog:
def sound(self):
print("Bark")

class Cat:
def sound(self):
print("Meow")

for animal in [Dog(), Cat()]:
animal.sound()

11.8 Benefits of OOP

  • Organizes code into reusable components.
  • Supports inheritance and code reuse.
  • Helps represent real-world entities.
  • Improves maintainability of large programs.

Chapter 12: Exception Handling

12.1 What is an Exception?

An exception is an event that occurs during program execution and interrupts the normal flow. If an exception is not handled, the program may terminate unexpectedly.

12.2 Common Exceptions

  • ValueError: An operation receives a value of an inappropriate form.
  • TypeError: An operation is applied to an unsuitable type.
  • ZeroDivisionError: Division or modulo by zero is attempted.
  • IndexError: A sequence index is outside the valid range.
  • KeyError: A dictionary key is not found.
  • FileNotFoundError: A requested file cannot be found.

12.3 try and except

The try block contains code that may raise an exception. The except block handles a matching exception.

try:
    number = int(input("Enter a number: "))
    print(100 / number)
except ValueError:
    print("Please enter a valid number")
except ZeroDivisionError:
    print("Cannot divide by zero")

12.4 else and finally

The else block executes when the try block completes without an exception. The finally block executes whether an exception occurs or not.

try:
    result = 10 / 2
except ZeroDivisionError:
    print("Division error")
else:
    print(result)
finally:
    print("Program completed")

12.5 Raising Exceptions

The raise statement allows a program to explicitly raise an exception when a condition is invalid.

age = -5

if age < 0:
raise ValueError("Age cannot be negative")

12.6 Custom Exceptions

A programmer can create a custom exception by defining a class derived from Exception.

class InvalidAgeError(Exception):
pass

age = -1

if age < 0:
raise InvalidAgeError("Age cannot be negative")

Python includes a standard library containing modules for mathematics, dates, file formats, operating-system interaction, networking and many other tasks.

13.7 External Packages

13.8 Using an External Package

Install external packages only when required. Some packages need additional configuration or a compatible Python version.

Chapter 14: Database Connectivity

14.1 Introduction

A database stores organized information. Python applications can connect to databases to insert, retrieve, update and delete records.

14.2 SQLite Database

SQLite is a lightweight relational database. Python includes the sqlite3 module, which can be used to create and work with SQLite databases without installing a separate database server.

14.3 Connecting to a Database

import sqlite3

connection = sqlite3.connect("college.db")
print("Database connected")

connection.close()

14.4 Creating a Table

import sqlite3

connection = sqlite3.connect("college.db")
cursor = connection.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS students (
id INTEGER PRIMARY KEY,
name TEXT,
course TEXT
)
""")

connection.commit()
connection.close()

14.5 Inserting Records

import sqlite3

connection = sqlite3.connect("college.db")
cursor = connection.cursor()

cursor.execute(
"INSERT INTO students (name, course) VALUES (?, ?)",
("Aman", "BCA")
)

connection.commit()
connection.close()

14.6 Retrieving Records

import sqlite3

connection = sqlite3.connect("college.db")
cursor = connection.cursor()

cursor.execute("SELECT * FROM students")
records = cursor.fetchall()

for record in records:
print(record)

connection.close()

14.7 Updating and Deleting Records

cursor.execute(
"UPDATE students SET course = ? WHERE id = ?",
("MCA", 1)
)

cursor.execute(
"DELETE FROM students WHERE id = ?",
(2,)
)

After data changes, call commit() to save the transaction. Use parameterized queries with placeholders instead of building SQL statements by joining untrusted input.

Database applications should handle errors, close connections properly and validate user input. Parameterized queries help protect against SQL injection.

Python is used in many areas of technology. Its flexibility and extensive ecosystem make it useful for building applications and automating tasks.

  • Web Development: Creating websites and web services.
  • Data Science: Analysing and visualizing information.
  • Artificial Intelligence: Building intelligent systems.
  • Automation: Performing repetitive computer tasks.

15.2 Mini Project: Simple Calculator

This program accepts two numbers and performs a selected arithmetic operation.

num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

print("1. Addition")
print("2. Subtraction")
print("3. Multiplication")
print("4. Division")

choice = input("Choose operation: ")

if choice == "1":
print(num1 + num2)
elif choice == "2":
print(num1 - num2)
elif choice == "3":
print(num1 * num2)
elif choice == "4":
if num2 != 0:
