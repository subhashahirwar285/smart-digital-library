Preface and Learning Outcomes

JavaScript is a programming language widely used to make websites interactive. It can respond to clicks, validate forms, update page content, communicate with web services and build applications. JavaScript also runs outside the browser in environments such as Node.js.

This book introduces JavaScript concepts step by step. Each chapter contains explanations, examples and revision questions. Beginners should type the examples themselves, run them in a browser or suitable JavaScript environment, and experiment with small changes.

Chapter 1: Introduction to JavaScript

1.1 What Is JavaScript?

JavaScript is a high-level programming language commonly used to create interactive web pages. HTML defines the structure of a page, CSS controls its presentation, and JavaScript adds behaviour and dynamic functionality.

For example, HTML can create a button, CSS can make it blue, and JavaScript can display a message when the user clicks it.

1.2 Main Uses

  • Responding to button clicks and keyboard input.
  • Validating form information before submission.
  • Updating page content without reloading the entire page.
  • Creating interactive menus, quizzes and calculators.
  • Communicating with remote APIs.
  • Building server-side applications with Node.js.

1.3 JavaScript and Java

JavaScript and Java are different programming languages despite their similar names. They have different language designs, runtimes and typical usage patterns. Knowledge of one can help with general programming concepts, but their syntax and development environments are not interchangeable.

1.4 Where Does JavaScript Run?

A browser contains a JavaScript engine that executes scripts. JavaScript can also run in environments such as Node.js, which provides APIs for server-side and command-line applications. Browser-specific features such as the DOM are not automatically available in every JavaScript environment.

1.5 How a Web Page Uses JavaScript

  1. The browser loads the HTML document.
  2. The browser processes the CSS used to style the page.
  3. JavaScript runs when the script is evaluated or when an event triggers a handler.
  4. The script can update the page, respond to users or request data.
Example: A quiz website can use JavaScript to check answers, calculate a score and show feedback immediately.

Chapter 2: Setup and Your First Program

2.1 Requirements

You can begin learning browser JavaScript with a modern web browser and a text editor. Create an HTML file and write JavaScript inside a script element, or put the JavaScript in a separate .js file.

2.2 JavaScript Inside HTML

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First JavaScript</title>
</head>
<body>
  <h1>Hello JavaScript</h1>

  <script>
    console.log("Hello, World!");
  </script>
</body>
</html>

Save the file with an .html extension and open it in a browser. Open the developer tools and select the Console panel to see the message.

2.3 External JavaScript File

For larger projects, keeping JavaScript in a separate file makes the code easier to organise and maintain.

<!-- index.html -->
<script src="script.js" defer></script>
// script.js
console.log("External JavaScript is working!");

The defer attribute makes an external classic script execute after the HTML has been parsed. This is helpful when the script needs to access page elements.

2.4 Console Output

console.log("Hello");
console.log(10 + 20);
console.warn("This is a warning");
console.error("This is an error message");

2.5 Displaying a Message

alert("Welcome to JavaScript!");

The alert function displays a browser dialog. It is useful for basic demonstrations, but modern websites usually display feedback inside the page instead of repeatedly opening dialogs.

2.6 Comments

// This is a single-line comment

/*
This is a
multi-line comment.
*/

Comments explain code to people reading it. They are not executed as JavaScript statements.

Chapter 3: Variables and Data Types

3.1 Variables

A variable is a named binding used to refer to a value. JavaScript provides let, const and var. In modern code, let is commonly used when a binding must be reassigned, while const is used when the binding should not be reassigned.

let age = 20;
const college = "My College";
let city = "Indore";

console.log(age);
console.log(college);
console.log(city);

3.2 let, const and var

KeywordReassignmentScopeTypical use
letAllowedBlock scopeValues that change
constNot allowed for the bindingBlock scopeBindings not reassigned
varAllowedFunction scopeLegacy code; use carefully

A const object or array can still have its contents changed. const prevents reassignment of the variable binding, not every possible mutation of the referenced object.

3.3 Primitive Data Types

  • String: Text, such as "Hello".
  • Number: Numeric values, including integers and decimals.
  • Boolean: true or false.
  • Undefined: A value commonly seen when a declared variable has not been assigned a value.
  • Null: A value intentionally used to represent the absence of an object value.
  • BigInt: Integers larger than the safe range of ordinary Number values.
  • Symbol: A primitive used to create unique identifiers.

3.4 Checking a Data Type

let name = "Subhash";
let age = 20;
let isStudent = true;

console.log(typeof name);      // string
console.log(typeof age);       // number
console.log(typeof isStudent); // boolean

One JavaScript quirk is that typeof null returns "object". This is a historical behaviour of the language, not evidence that null is an ordinary object.

3.5 Type Conversion

let textNumber = "25";

let numberValue = Number(textNumber);
console.log(numberValue + 5); // 30

let score = 90;
console.log(String(score));  // "90"

Explicit conversion helps avoid confusing results when strings and numbers are combined. For example, the + operator can concatenate strings rather than add numeric values.

3.6 Naming Rules

Variable names can contain letters, digits, underscores and dollar signs, but they cannot begin with a digit. Names are case-sensitive. For example, totalMarks and totalmarks are different identifiers. Use meaningful names such as studentName instead of unclear names such as x1.

Chapter 4: Operators in JavaScript

4.1 Arithmetic Operators

Arithmetic operators perform mathematical operations. The main operators are +, -, *, /, %, ** and increment/decrement operators.

let a = 10;
let b = 3;

console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.333...
console.log(a % b);  // 1
console.log(a ** b); // 1000

4.2 Assignment Operators

let score = 10;
score += 5;  // score is now 15
score *= 2;  // score is now 30
score -= 4;  // score is now 26

4.3 Comparison Operators

Comparison operators return a Boolean result. They include >, <, >=, <=, === and !==. Prefer strict equality operators when you want to compare values without automatic type conversion.

console.log(5 === 5);   // true
console.log(5 === "5"); // false
console.log(5 == "5");  // true
console.log(8 > 3);     // true

4.4 Logical Operators

The logical AND operator (&&), OR operator (||) and NOT operator (!) are used in conditions. In JavaScript, && and || can return one of their operands rather than always returning true or false.

let age = 20;
let hasID = true;

console.log(age >= 18 && hasID); // true
console.log(age < 18 || hasID);  // true
console.log(!hasID);             // false

4.5 Increment and Decrement

let count = 5;
count++;
console.log(count); // 6

count--;
console.log(count); // 5

4.6 Ternary Operator

The conditional or ternary operator is a short expression for choosing between two values.

let age = 20;
let result = age >= 18 ? "Adult" : "Minor";
console.log(result); // Adult

4.7 Operator Precedence

Operators follow precedence rules that determine evaluation order. Parentheses make the intended order clearer.

let result = (2 + 3) * 4;
console.log(result); // 20

Chapter 5: Conditional Statements

5.1 if Statement

The if statement executes a block when its condition is truthy.

let age = 20;

if (age >= 18) {
    console.log("Eligible by age");
}

5.2 if...else

let number = 7;

if (number % 2 === 0) {
    console.log("Even");
} else {
    console.log("Odd");
}

5.3 else if

An else if chain checks multiple conditions in order. The first matching branch is executed.

let marks = 78;

if (marks >= 90) {
    console.log("Grade A");
} else if (marks >= 75) {
    console.log("Grade B");
} else if (marks >= 50) {
    console.log("Grade C");
} else {
    console.log("Needs improvement");
}

5.4 switch Statement

A switch statement compares one expression against case values. Use break when you want to prevent execution from falling through into the next case.

let day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    default:
        console.log("Other day");
}

5.5 Truthy and Falsy Values

JavaScript conditions convert values to Boolean form. Values such as false, 0, -0, 0n, an empty string, null, undefined and NaN are falsy. Most other values, including empty arrays and empty objects, are truthy.

5.6 Nested Conditions

A nested condition is an if statement inside another conditional block. Nesting can be useful, but overly complex nesting can make code difficult to understand. Clear conditions and early returns can sometimes simplify the logic.

Chapter 6: Loops in JavaScript

6.1 What Is a Loop?

A loop repeats a block of code while a condition or iteration rule allows it to continue. Loops are useful for processing lists, counting, repeating calculations and traversing data.

6.2 for Loop

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output: 1, 2, 3, 4, 5. The initialisation runs once, the condition is checked before each iteration, and the update expression normally runs after the body.

6.3 while Loop

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

A while loop checks the condition before running its body. If the condition is false at the start, the body does not execute.

6.4 do...while Loop

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

A do...while loop executes the body at least once because its condition is checked afterward.

6.5 for...of

The for...of loop iterates over values from iterable objects such as arrays and strings.

const colors = ["Blue", "Green", "Yellow"];

for (const color of colors) {
    console.log(color);
}

6.6 break and continue

break exits the nearest loop. continue skips the remainder of the current iteration and proceeds to the next one.

for (let i = 1; i <= 10; i++) {
    if (i === 4) continue;
    if (i === 8) break;
    console.log(i);
}

6.7 Nested Loops

A nested loop is a loop inside another loop. It is often used for tables, grids and combinations. Since the inner loop runs for each outer iteration, nested loops can increase the amount of work significantly.

for (let row = 1; row <= 3; row++) {
    let line = "";
    for (let col = 1; col <= 3; col++) {
        line += "* ";
    }
    console.log(line);
}

Practice Programs

  1. Print numbers from 1 to 100.
  2. Print the multiplication table of a number.
  3. Calculate the sum of the first N natural numbers.
  4. Calculate a factorial using a loop.
  5. Print a simple star pattern.

Chapter 7: Functions

7.1 Meaning of a Function

A function is a reusable block of code that performs a task. Functions help organise programs into smaller units, reduce duplication and make testing easier.

7.2 Function Declaration

function greet() {
    console.log("Welcome!");
}

greet();

7.3 Parameters and Arguments

Parameters are names listed in a function definition. Arguments are the values supplied when the function is called.

function greetUser(name) {
    console.log("Hello, " + name);
}

greetUser("Aman");

7.4 Return Statement

The return statement sends a value back to the caller and ends the current function execution.

function add(a, b) {
    return a + b;
}

const result = add(10, 20);
console.log(result); // 30

7.5 Function Expressions

const multiply = function(a, b) {
    return a * b;
};

console.log(multiply(4, 5));

7.6 Arrow Functions

Arrow functions provide a concise way to write function expressions. They do not have their own this binding, so they are not interchangeable with ordinary functions in every context.

const square = number => number * number;
console.log(square(6)); // 36

const add = (a, b) => a + b;
console.log(add(2, 3)); // 5

7.7 Default Parameters

function welcome(name = "Student") {
    return `Welcome, ${name}!`;
}

console.log(welcome());
console.log(welcome("Aman"));

7.8 Scope

Scope determines where a variable can be accessed. Variables declared with let and const have block scope, while var has function scope. Functions can access variables in enclosing scopes according to JavaScript's lexical scoping rules.

7.9 Recursion

Recursion occurs when a function calls itself. A recursive function needs a base case to stop recursion and prevent unbounded calls.

function factorial(n) {
    if (n < 0) return undefined;
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

console.log(factorial(5)); // 120

Chapter 8: Arrays

8.1 What Is an Array?

An array stores an ordered collection of values. Its indexes are zero-based, meaning the first item is at index 0. Arrays can hold values of different types, although keeping related data consistent often makes code easier to maintain.

const fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Mango

8.2 Reading and Updating Items

const numbers = [10, 20, 30];

numbers[1] = 25;

console.log(numbers); // [10, 25, 30]
console.log(numbers.length); // 3

8.3 Common Array Methods

  • push: Adds an item to the end.
  • pop: Removes the last item.
  • unshift: Adds an item to the beginning.
  • shift: Removes the first item.
  • includes: Checks whether a value is present.
  • indexOf: Finds the first matching index.
  • slice: Returns a selected shallow copy without changing the original array.
  • splice: Can remove, replace or insert items in the original array.
const colors = ["Blue", "Green"];

colors.push("Yellow");
console.log(colors);

colors.pop();
console.log(colors);

console.log(colors.includes("Blue"));

8.4 Looping Through an Array

const marks = [70, 85, 90];

for (const mark of marks) {
    console.log(mark);
}

8.5 Arrays of Objects

Arrays often store objects representing related records. For example, a library application can store a list of books, each with a title and author.

const books = [
    { title: "JavaScript Basics", author: "A. Kumar" },
    { title: "Web Development", author: "R. Sharma" }
];

console.log(books[0].title);

8.6 Copying Arrays

Assigning an array to another variable copies its reference rather than creating an independent array. Spread syntax or slice can create a shallow copy. Nested objects inside that array may still be shared.

const original = [1, 2, 3];
const copy = [...original];

copy.push(4);

console.log(original); // [1, 2, 3]
console.log(copy);     // [1, 2, 3, 4]

Chapter 9: Strings and Template Literals

9.1 Strings

A string represents text. Strings can be written using single quotes, double quotes or backticks. Strings are immutable, meaning their individual characters cannot be changed in place; string methods return new strings or other values.

const firstName = "Aman";
const city = 'Indore';
const message = `Hello ${firstName}`;

console.log(message);

9.2 String Length and Access

const text = "JavaScript";

console.log(text.length);
console.log(text[0]);
console.log(text.charAt(1));

9.3 Common String Methods

const text = "  Learn JavaScript  ";

console.log(text.trim());
console.log(text.toUpperCase());
console.log(text.toLowerCase());
console.log(text.includes("Java"));
console.log(text.replace("JavaScript", "Programming"));
console.log(text.slice(2, 7));

9.4 Template Literals

Template literals use backticks and allow expressions to be inserted with ${...}. They also support multi-line strings.

const name = "Aman";
const marks = 85;

const result = `${name} scored ${marks} marks.`;
console.log(result);

9.5 Splitting and Joining

const sentence = "HTML CSS JavaScript";
const words = sentence.split(" ");

console.log(words);

const combined = words.join(", ");
console.log(combined);

9.6 Comparing Strings

String comparison is case-sensitive. For example, "hello" and "Hello" are different strings. When comparing text from users, consider whether normalisation or case-insensitive matching is appropriate for the application.

Chapter 10: Objects

10.1 What Is an Object?

An object stores related data as properties. A property consists of a key and a value. Object values can include strings, numbers, arrays, functions and other objects.

const student = {
    name: "Aman",
    age: 20,
    course: "BCA"
};

console.log(student.name);
console.log(student["course"]);

10.2 Adding and Updating Properties

const book = {
    title: "JavaScript Basics",
    pages: 200
};

book.author = "A. Kumar";
book.pages = 250;

console.log(book);

10.3 Methods

A method is a function stored as an object property.

const user = {
    name: "Aman",
    greet() {
        return `Hello, ${this.name}`;
    }
};

console.log(user.greet());

In an ordinary method call, this usually refers to the object used before the dot. Arrow functions do not create their own this binding.

10.4 Object Destructuring

const student = {
    name: "Aman",
    age: 20
};

const { name, age } = student;

console.log(name);
console.log(age);

10.5 Object Keys and Values

const scores = {
    maths: 80,
    science: 90
};

console.log(Object.keys(scores));
console.log(Object.values(scores));
console.log(Object.entries(scores));

10.6 Spread Syntax

const first = { name: "Aman", age: 20 };
const updated = { ...first, city: "Indore" };

console.log(updated);

Object spread creates a shallow copy of enumerable own properties. Nested objects remain shared unless they are copied separately.

10.7 Arrays vs Objects

ArrayObject
Designed for ordered collectionsDesigned for named properties
Commonly accessed by numeric indexCommonly accessed by property key
Provides methods such as map and filterProvides methods such as Object.keys and Object.values

Chapter 11: DOM Manipulation

11.1 What Is the DOM?

The Document Object Model (DOM) represents an HTML document as a structured set of objects. JavaScript can use DOM APIs to find elements, read or update text, change attributes, modify styles and create new elements.

11.2 Selecting Elements

document.getElementById("title");
document.querySelector(".message");
document.querySelectorAll("p");

getElementById selects an element by ID. querySelector returns the first element matching a CSS selector. querySelectorAll returns a collection of all matching elements.

11.3 Changing Text and HTML

// HTML: <h2 id="title">Old title</h2>

const title = document.getElementById("title");
title.textContent = "New title";

Use textContent for plain text. Setting innerHTML interprets a string as HTML, so untrusted user input should not be inserted with innerHTML because it can create cross-site scripting risks.

11.4 Changing CSS Classes

const box = document.querySelector(".box");

box.classList.add("active");
box.classList.remove("hidden");
box.classList.toggle("selected");

11.5 Creating Elements

const item = document.createElement("li");
item.textContent = "New book";

document.getElementById("bookList").appendChild(item);

The HTML page must contain an element with the ID bookList for this example to work.

11.6 Reading Input Values

// HTML: <input id="username" value="Aman">

const input = document.getElementById("username");
console.log(input.value);

11.7 Removing Elements

const message = document.querySelector(".message");

if (message) {
    message.remove();
}
Practical use: A digital library can use DOM manipulation to add book cards, show search results, update reading progress and display feedback.

Chapter 12: Events in JavaScript

12.1 What Is an Event?

An event represents something that occurs in the browser, such as a click, key press, form submission or page load. JavaScript event handlers allow programs to respond to these activities.

12.2 Click Event

<button id="myButton">Click Me</button>
<p id="output"></p>

<script>
document.getElementById("myButton")
    .addEventListener("click", function() {
        document.getElementById("output").textContent =
            "Button clicked!";
    });
</script>

12.3 addEventListener

addEventListener attaches a handler for a particular event. It is generally more flexible than assigning an inline event handler because it separates behaviour from HTML and allows multiple listeners.

12.4 Keyboard Events

document.addEventListener("keydown", function(event) {
    console.log("Key pressed:", event.key);
});

12.5 Form Submit Event

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {
    event.preventDefault();
    console.log("Form submission handled.");
});

preventDefault prevents the browser's default action for the event. In this example, it prevents the normal form submission so JavaScript can handle the form.

12.6 Event Object

The event object contains information about the event. Its properties can identify the target element, key pressed or other details. The available information depends on the event type.

12.7 Event Bubbling

Many DOM events bubble from a target element through its ancestors. Event delegation takes advantage of this behaviour by attaching one handler to a parent element and identifying which child triggered the event.

Chapter 13: Form Validation

13.1 Why Validate Forms?

Form validation checks whether submitted information meets the application's requirements. Examples include checking required fields, email format, password length and whether numeric values fall within an allowed range.

13.2 HTML Validation

<form id="signupForm">
  <label>Name:
    <input id="name" required minlength="2">
  </label>

  <label>Email:
    <input id="email" type="email" required>
  </label>

  <button type="submit">Create Account</button>
</form>

HTML attributes such as required, type="email", min, max and minlength provide useful browser-side checks.

13.3 JavaScript Validation

const form = document.getElementById("signupForm");

form.addEventListener("submit", function(event) {
    const name = document.getElementById("name").value.trim();
    const email = document.getElementById("email").value.trim();

    if (name.length < 2 || email === "") {
        event.preventDefault();
        alert("Please enter a valid name and email.");
    }
});

This example assumes the form and input elements exist in the HTML. It demonstrates basic client-side checks, not complete email verification.

13.4 Client-Side and Server-Side Validation

Client-side validation improves usability by giving immediate feedback. However, users can bypass browser-side checks. A server must validate incoming data independently before saving it or performing sensitive actions.

13.5 Safe Form Handling

  • Tell users clearly which fields are required.
  • Validate data on the client for usability.
  • Repeat important validation on the server.
  • Never trust submitted values simply because a browser form was used.
  • Display error messages that help users correct their input.

Practice Tasks

  1. Validate a required name field.
  2. Check that a password meets a minimum length.

  4. Explain why server-side validation is necessary.

Chapter 14: Modern JavaScript (ES6+)

14.1 let and const

Modern JavaScript commonly uses let and const for block-scoped bindings. They help make reassignment and scope easier to reason about than older var-based patterns.

14.2 Arrow Functions

const double = n => n * 2;
console.log(double(5)); // 10

14.3 Template Literals

const name = "Aman";
console.log(`Welcome, ${name}!`);

14.4 Destructuring

const user = { name: "Aman", age: 20 };
const { name, age } = user;

const numbers = [10, 20];
const [first, second] = numbers;

console.log(name, age, first, second);

14.5 Spread Syntax

const first = [1, 2];
const second = [...first, 3, 4];

console.log(second);

14.6 Rest Parameters

Rest parameters collect remaining arguments into an array.

function sum(...numbers) {
    return numbers.reduce((total, n) => total + n, 0);
}

console.log(sum(1, 2, 3, 4)); // 10

14.7 Default Parameters

function greet(name = "Student") {
    return `Hello, ${name}`;
}

console.log(greet());

14.8 Modules

JavaScript modules let code be divided into separate files. An export makes selected values available to other modules, while import brings them into another module. In browsers, modules normally use type="module" and are best tested through a local development server or supported web server.

// math.js
export function add(a, b) {
    return a + b;
}

// app.js
import { add } from "./math.js";
console.log(add(2, 3));

Chapter 15: Important Array Methods

15.1 forEach()

forEach runs a callback for each array element. It is useful for side effects such as displaying values. It does not create a new array of returned callback values.

[1, 2, 3].forEach(number => {
    console.log(number);
});

15.2 map()

map creates a new array by applying a callback to every element.

const numbers = [1, 2, 3];
const doubled = numbers.map(n => n * 2);

console.log(doubled); // [2, 4, 6]

15.3 filter()

filter creates a new array containing elements that pass a test.

const numbers = [1, 2, 3, 4, 5, 6];
const even = numbers.filter(n => n % 2 === 0);

console.log(even); // [2, 4, 6]

15.4 reduce()

reduce combines array elements into a single accumulated result. Supplying an initial value is often clearer and avoids errors with empty arrays.

const prices = [100, 200, 300];

const total = prices.reduce(
    (sum, price) => sum + price,
    0
);

console.log(total); // 600

15.5 find() and some()

const numbers = [4, 7, 10, 13];

console.log(numbers.find(n => n > 8)); // 10
console.log(numbers.some(n => n > 12)); // true
console.log(numbers.every(n => n > 0)); // true

15.6 sort()

By default, sort converts array values to strings and sorts according to string order. For numeric sorting, supply a comparison function.

const numbers = [40, 5, 100, 25];

numbers.sort((a, b) => a - b);
console.log(numbers); // [5, 25, 40, 100]

15.7 Choosing the Right Method

MethodPurpose
forEachPerform an action for each item
mapTransform every item into a new array
filterSelect items that pass a condition
reduceAccumulate a single result
findReturn the first matching item
someCheck whether at least one item passes a test
everyCheck whether all items pass a test

Chapter 16: Error Handling and Debugging

16.1 Types of Errors

A syntax error occurs when code does not follow valid language grammar. A runtime error occurs while code is executing. A logical error occurs when a program runs but produces an incorrect result.

16.2 try...catch

try...catch lets a program handle certain exceptions instead of allowing them to propagate without handling.

try {
    const data = JSON.parse("{invalid}");
    console.log(data);
} catch (error) {
    console.log("Could not parse the data.");
}

16.3 finally

A finally block runs after the try/catch process whether or not an exception was thrown, making it useful for cleanup actions.

try {
    console.log("Working...");
} catch (error) {
    console.log("An error occurred.");
} finally {
    console.log("Finished.");
}

16.4 Throwing Errors

function divide(a, b) {
    if (b === 0) {
        throw new Error("Cannot divide by zero.");
    }

    return a / b;
}

try {
    console.log(divide(10, 0));
} catch (error) {
    console.log(error.message);
}

16.5 Debugging with Console

console.log can show intermediate values. console.error can report errors. Browser developer tools also provide breakpoints, call stacks, variable inspection and step-by-step execution.

16.6 Debugging Strategy

  1. Reproduce the problem consistently.
  2. Read the complete error message.
  3. Identify the relevant line and variable values.
  4. Test a small hypothesis about the cause.
  5. Change the code and run the test again.
  6. Check that the fix does not break other features.

Chapter 17: JSON and Browser Storage

17.1 What Is JSON?

JSON stands for JavaScript Object Notation. It is a text format used to exchange structured data. JSON supports strings, numbers, Booleans, null, arrays and objects. JSON property names and string values use double quotes.

{
  "name": "Aman",
  "age": 20,
  "skills": ["HTML", "CSS", "JavaScript"]
}

17.2 JSON.stringify()

JSON.stringify converts a supported JavaScript value into JSON text.

const student = {
    name: "Aman",
    age: 20
};

const jsonText = JSON.stringify(student);
console.log(jsonText);

17.3 JSON.parse()

JSON.parse converts valid JSON text into a JavaScript value. Invalid JSON throws a syntax error, so data from unreliable sources should be parsed with appropriate error handling.

const text = '{"name":"Aman","age":20}';
const student = JSON.parse(text);

console.log(student.name);

17.4 localStorage

localStorage stores string values in the browser for an origin. Data normally persists across browser restarts until removed by the user or application, subject to browser storage rules. Do not store passwords or sensitive secrets in localStorage.

localStorage.setItem("theme", "dark");

const theme = localStorage.getItem("theme");
console.log(theme);

localStorage.removeItem("theme");

17.5 Saving Objects

const settings = {
    fontSize: 18,
    theme: "light"
};

localStorage.setItem("settings", JSON.stringify(settings));

const savedText = localStorage.getItem("settings");
const savedSettings = savedText
    ? JSON.parse(savedText)
    : null;

console.log(savedSettings);

17.6 sessionStorage

sessionStorage stores string values for a browser tab's page session. It is useful for temporary state that should not normally persist after the tab's session ends.

17.7 Storage Limitations

Browser storage has size limits and can be unavailable in some restricted environments. Applications should handle parsing failures and storage errors. Important data should not rely solely on local browser storage.

Chapter 18: Asynchronous JavaScript

18.1 Synchronous Code

Synchronous code normally runs one statement after another. A long-running operation can delay subsequent work in the same execution flow. JavaScript environments use event-loop mechanisms to coordinate asynchronous tasks.

18.2 setTimeout()

console.log("First");

setTimeout(() => {
    console.log("Later");
}, 1000);

console.log("Second");

Typical output order is First, Second, Later. The timeout schedules a callback after a minimum delay; it does not guarantee execution at an exact time.

18.3 Callbacks

A callback is a function passed to another function so that it can be invoked later or when an operation reaches a particular point. Callbacks are common in event handlers and asynchronous APIs.

18.4 Promises

A Promise represents the eventual result of an asynchronous operation. A promise can be pending, fulfilled or rejected. then handles successful fulfillment, catch handles rejection, and finally can run cleanup logic.

const task = new Promise((resolve, reject) => {
    const success = true;

    if (success) {
        resolve("Task completed");
    } else {
        reject(new Error("Task failed"));
    }
});

task
    .then(result => console.log(result))
    .catch(error => console.log(error.message));

18.5 async and await

An async function returns a Promise. The await expression pauses that async function until the awaited promise settles, allowing asynchronous code to be written in a sequential style.

function waitOneSecond() {
    return new Promise(resolve => {
        setTimeout(resolve, 1000);
    });
}

async function runTask() {
    console.log("Start");
    await waitOneSecond();
    console.log("Finished waiting");
}

runTask();

18.6 Handling Errors with async/await

async function loadData() {
    try {
        const response = await fetch("/data.json");

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error("Could not load data:", error.message);
    }
}

This example requires a server route or file that returns valid JSON. The relative URL will not work in every local-file setup.

18.7 Why Asynchronous Programming Matters

Network requests, timers and many I/O operations complete later. Asynchronous programming helps an application remain responsive while it waits for such work. Correct error handling remains important because requests can fail, time out or return unexpected data.

Chapter 19: Fetch API and Web APIs

19.1 What Is an API?

An Application Programming Interface (API) defines how software components communicate. A web API allows a client application to request data or actions from a server through a defined interface.

19.2 HTTP Basics

HTTP is a protocol used for communication between clients and servers. Common methods include GET for retrieving a resource, POST for submitting data, PUT for replacing a resource, PATCH for partial updates and DELETE for requesting removal. Actual server behaviour depends on its implementation and permissions.

19.3 Fetch API

The Fetch API makes network requests and returns a Promise. A fulfilled fetch promise does not automatically mean the HTTP status was successful, so check response.ok or response.status.

async function loadPosts() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/posts/1"
        );

        if (!response.ok) {
            throw new Error(`HTTP error: ${response.status}`);
        }

        const post = await response.json();
        console.log(post.title);
    } catch (error) {
        console.error("Request failed:", error.message);
    }
}

loadPosts();

This example uses a public demonstration API. Internet access, server availability and browser cross-origin policies can affect the result.

19.4 Sending JSON

async function createPost() {
    const data = {
        title: "My Post",
        body: "Learning JavaScript",
        userId: 1
    };

    const response = await fetch(
        "https://jsonplaceholder.typicode.com/posts",
        {
            method: "POST",
            headers: {
                "Content-Type": "application/json"
            },
            body: JSON.stringify(data)
        }
    );

    if (!response.ok) {
        throw new Error("Could not submit data");
    }

    return response.json();
}

A demonstration API may simulate creation rather than permanently save the submitted record.

19.5 Displaying API Data

async function showPost() {
    const response = await fetch(
        "https://jsonplaceholder.typicode.com/posts/1"
    );

    if (!response.ok) {
        throw new Error("Could not load post");
    }

    const post = await response.json();

    const output = document.getElementById("output");
    output.textContent = post.title;
}

The HTML must include an element such as <div id="output"></div> for this example.

19.6 API Errors and Security

  • Check HTTP status codes and handle rejected requests.
  • Validate returned data before using it.
  • Do not expose secret API keys in public browser code.
  • Use HTTPS for sensitive network communication.
  • Remember that CORS is controlled by server response policies.

    if (operator === "+") return a + b;
    if (operator === "-") return a - b;
    if (operator === "*") return a * b;

    if (operator === "/") {
        if (b === 0) return "Cannot divide by zero";

JavaScript Glossary

  • Variable: A named binding that refers to a value.
  • Data Type: A category describing the kind of value.
  • Function: A reusable unit of code.
  • Parameter: A named input in a function definition.
  • Argument: A value supplied when calling a function.
  • Array: An ordered collection of values.
  • Object: A collection of properties.
  • DOM: Document Object Model.
  • Event: An occurrence to which code can respond.
  • Callback: A function passed to another function.
  • Promise: An object representing an eventual asynchronous result.
  • JSON: JavaScript Object Notation, a text data format.
  • API: Application Programming Interface.
  • localStorage: Browser storage for string key-value pairs.
  • Scope: The region where a binding can be accessed.
  • Arrow Function: A concise function expression using => syntax.
  • Exception: An error or unusual condition represented through JavaScript's exception mechanism.
  • Fetch API: A browser interface for making network requests.
