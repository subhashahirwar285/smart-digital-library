Chapter 1: Introduction to Data Structures

A data structure is a method of organizing and storing data in a computer so that it can be accessed and modified efficiently.

Why Are Data Structures Important?

  • They organize large amounts of information.
  • They improve program efficiency.
  • They make searching and sorting easier.
  • They help manage memory effectively.
  • They are used in databases, operating systems and applications.

Basic Operations

  • Insertion: Adding a new element.
  • Deletion: Removing an element.
  • Searching: Finding an element.
  • Sorting: Arranging elements in order.
  • Traversal: Visiting each element.
  • Updating: Changing an existing element.
Example: A contact list stores names and phone numbers in an organized way. A suitable data structure makes it easier to search for a contact.

Chapter 2: Classification of Data Structures

1. Primitive Data Structures

These are basic data types provided by programming languages.

  • Integer

  • Character
  • Boolean

2. Non-Primitive Data Structures

These are formed using primitive data types.

  • Array
  • Linked List
  • Stack
  • Queue
  • Tree
  • Graph

Linear Data Structures

Elements are arranged in a sequence. Examples include arrays, linked lists, stacks and queues.

Non-Linear Data Structures

Elements are connected in hierarchical or network form. Examples include trees and graphs.

Chapter 3: Arrays

An array is a collection of elements of the same data type stored in contiguous memory locations. Each element is accessed using an index.

Types of Arrays

  • One-dimensional array
  • Two-dimensional array
  • Multidimensional array

Declaration in C

int numbers[5] = {10, 20, 30, 40, 50};

Traversing an Array

#include <stdio.h>

int main() {
    int a[5] = {10, 20, 30, 40, 50};

    for(int i = 0; i < 5; i++) {
        printf("%d ", a[i]);
    }

    return 0;
}

Advantages

  • Fast access using index.
  • Easy to traverse.
  • Simple to implement.

Limitations

  • Fixed size in ordinary static arrays.
  • Insertion and deletion may require shifting elements.

Chapter 4: Linked Lists

A linked list is a linear data structure in which elements are stored in nodes. Each node contains data and a pointer to the next node.

Structure of a Node in C

struct Node {
    int data;
    struct Node *next;
};

Types of Linked Lists

  • Singly Linked List
  • Doubly Linked List
  • Circular Linked List
HEAD → [10 | next] → [20 | next] → [30 | NULL]

Advantages

  • Dynamic memory allocation.
  • Can grow or shrink during execution.
  • Insertion and deletion can be efficient when the position is known.

Limitations

  • No direct index-based access.
  • Extra memory is required for pointers.

Chapter 5: Stacks

A stack is a linear data structure that follows the LIFO principle: Last In, First Out. The element inserted last is removed first.

Basic Stack Operations

  • Push: Insert an element.
  • Pop: Remove the top element.
  • Peek: View the top element.
  • isEmpty: Check whether the stack is empty.
TOP → | 30 |
      | 20 |
      | 10 |
      -----

Push Operation in C

The push operation inserts a new value at the top of the stack. If the stack is full, stack overflow occurs.

void push(int value) {
    if(top == SIZE - 1) {
        printf("Stack Overflow");
    } else {
        stack[++top] = value;
    }
}

Applications of Stack

  • Function calls and recursion.
  • Undo and redo operations.
  • Expression evaluation.
  • Browser history navigation.

Chapter 6: Queues

A queue is a linear data structure that follows FIFO: First In, First Out. The first inserted element is removed first.

Basic Operations

  • Enqueue: Insert an element at the rear.
  • Dequeue: Remove an element from the front.
  • Front: View the first element.
  • Rear: View the last element.
FRONT → [10] [20] [30] ← REAR

Types of Queues

  • Simple Queue
  • Circular Queue
  • Priority Queue
  • Deque (Double Ended Queue)

Applications

  • Printer scheduling.
  • CPU task scheduling.
  • Customer service systems.
  • Data buffering.

Chapter 7: Trees

A tree is a non-linear hierarchical data structure made up of nodes connected by edges.

Important Terminology

  • Root: The topmost node.
  • Parent: A node having child nodes.
  • Child: A node connected below another node.
  • Leaf: A node without children.
  • Edge: A connection between two nodes.
  • Height: The longest downward path from a node to a leaf, measured in edges.
      10
    /  \
   5   15
  / \  / \
 2  7 12 18

Tree Traversal

  • Preorder: Root, Left, Right.
  • Inorder: Left, Root, Right.
  • Postorder: Left, Right, Root.

Applications

File systems, organization charts, database indexing and decision-making systems use tree structures.

Chapter 8: Binary Search Trees

A Binary Search Tree (BST) is a binary tree in which values smaller than a node are placed in its left subtree and values greater than a node are placed in its right subtree.

     50
    /  \
  30   70
 / \  / \
20 40 60 80

Important Operations

  • Insertion
  • Searching
  • Deletion
  • Traversal

Searching in a BST

Compare the target value with the current node. Move left if the target is smaller and right if it is larger.

Advantages

  • Supports ordered data storage.
  • Searching can be efficient in a balanced BST.
  • Inorder traversal produces sorted values.
A BST can become unbalanced. In that case, searching may take O(n) time.

Types of Graphs

  • Undirected Graph

  • Unweighted Graph

Chapter 10: Searching Algorithms

Searching is the process of finding a particular element in a collection of data.

1. Linear Search

Linear Search checks each element one by one until the required value is found or the list ends.

int a[] = {10, 20, 30, 40, 50};
int key = 30;

for(int i = 0; i < 5; i++) {
    if(a[i] == key) {
        printf("Found");
        break;
    }
}

Time Complexity: O(n) in the worst case.

2. Binary Search

Binary Search repeatedly divides the search range into two halves. It requires the array to be sorted.

int a[] = {10, 20, 30, 40, 50};
int key = 40;
int low = 0, high = 4;

while(low <= high) {
    int mid = low + (high - low) / 2;

    if(a[mid] == key) {
        printf("Found");
        break;
    }
    else if(a[mid] < key) {
        low = mid + 1;
    }
    else {
        high = mid - 1;
    }
}

Comparison

  • Linear Search works on sorted and unsorted arrays.
  • Binary Search requires sorted data.
  • Linear Search worst-case time: O(n).
  • Binary Search worst-case time: O(log n).

Chapter 11: Sorting Algorithms

Sorting is the process of arranging data in a particular order, such as ascending or descending order.

1. Bubble Sort

Bubble Sort compares adjacent elements and swaps them when they are in the wrong order. This process continues until the array is sorted.

int a[] = {5, 3, 8, 2, 1};
int n = 5;

for(int i = 0; i < n - 1; i++) {
    for(int j = 0; j < n - i - 1; j++) {
        if(a[j] > a[j + 1]) {
            int temp = a[j];
            a[j] = a[j + 1];
            a[j + 1] = temp;
        }
    }
}

After sorting, the array becomes: 1, 2, 3, 5, 8.

Worst-case Time Complexity: O(n²).

2. Selection Sort

Selection Sort repeatedly selects the smallest element from the unsorted part and places it at the beginning.

3. Insertion Sort

Insertion Sort builds a sorted section by inserting each new element into its correct position.

4. Merge Sort

Merge Sort divides the array into smaller parts, sorts them and merges the sorted parts. Its time complexity is O(n log n).

5. Quick Sort

Quick Sort selects a pivot element and partitions the array around the pivot. Its average time complexity is O(n log n).

Chapter 12: Hashing

Hashing is a technique used to map a key to an index in a hash table using a hash function.

Hash Function

A hash function converts a key into a table index.

index = key % table_size;

Collision

A collision occurs when two different keys produce the same hash table index.

Collision Handling Methods

  • Chaining
  • Linear Probing
  • Quadratic Probing
  • Double Hashing

Applications

  • Database indexing.
  • Symbol tables in compilers.
  • Fast data lookup.
  • Caching systems.

Chapter 13: Time and Space Complexity

Algorithm analysis helps us understand how much time and memory an algorithm requires as the input size increases.

Time Complexity

Time complexity describes how the number of operations grows with input size.

O(1) - Constant Time

The number of operations remains approximately constant as input size changes.

printf("%d", a[0]);

O(n) - Linear Time

A single loop processes n elements.

for(int i = 0; i < n; i++) {
    printf("%d", a[i]);
}

O(n²) - Quadratic Time

A nested loop can perform approximately n multiplied by n operations.

for(int i = 0; i < n; i++) {
    for(int j = 0; j < n; j++) {
        printf("*");
    }
}

O(log n) - Logarithmic Time

Binary Search reduces the remaining search range by half in each step.

Common Complexity Classes

  • O(1): Constant
  • O(log n): Logarithmic
  • O(n): Linear
  • O(n log n): Linearithmic
  • O(n²): Quadratic

Space Complexity

Space complexity describes the additional memory an algorithm needs while it runs.

An efficient algorithm generally aims to reduce unnecessary time and memory usage.

2. Database Management

Trees and hashing help organize, index and retrieve records efficiently.

3. Web Browsers
