Chapter 1: Introduction to C++ Programming

1.1 What is C++?

C++ is a general-purpose, compiled programming language developed by Bjarne Stroustrup at Bell Laboratories. It was originally designed as an extension of the C programming language and supports both procedural and object-oriented programming.

1.2 History of C++

C++ development began in 1979 under the name C with Classes. The language was later renamed C++ in 1983. It introduced classes and other object-oriented features while retaining many capabilities of C.

1.3 Features of C++

  • Object-Oriented: Supports classes and objects.
  • Multi-Paradigm: Supports procedural, object-oriented and generic programming.
  • Fast Execution: Compiled programs can provide high performance.
  • Reusability: Supports code reuse through classes and inheritance.
  • Function Overloading: Allows functions with the same name and different parameters.
  • Templates: Support generic programming.
  • Standard Library: Provides containers, algorithms and utilities.

1.4 Applications of C++

C++ is used in game development, desktop applications, operating systems, browsers, embedded systems, graphics software, simulations and financial applications.

1.5 Difference Between C and C++

  • C mainly follows procedural programming, while C++ supports procedural and object-oriented programming.
  • C uses structures, while C++ supports classes with access control and member functions.
  • C++ supports function overloading; standard C does not.
  • C++ provides features such as inheritance and polymorphism.
  • C++ includes a standard library with containers such as vector and map.

1.6 Object-Oriented Programming

Object-oriented programming (OOP) is a programming approach that organizes software around objects. An object combines data and functions that operate on that data.

Important: The four commonly taught pillars of OOP are encapsulation, abstraction, inheritance and polymorphism.

Chapter 2: Structure of a C++ Program

2.1 Basic Structure

A C++ program generally contains header inclusions, declarations, function definitions and executable statements. The main() function is the entry point of a typical hosted C++ application.

2.2 First C++ Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, World!";
    return 0;
}

2.3 Explanation

  • #include <iostream> provides input and output stream facilities.
  • using namespace std; makes names from the standard namespace available without writing std:: each time.
  • int main() defines the main function.
  • cout displays output.
  • << is the stream insertion operator.
  • return 0; indicates successful program completion.

2.4 Comments in C++

Comments are explanatory notes in source code. They are ignored by the compiler.

// Single-line comment

/*
Multi-line
comment
*/

2.5 Compilation and Execution

Save the source file with a .cpp extension. Using the GCC C++ compiler, compile it with:

g++ hello.cpp -o hello

On Windows, run:

hello.exe

2.6 Namespace

A namespace groups related identifiers and helps prevent naming conflicts. The standard C++ library uses the std namespace.

Chapter 3: Variables, Constants and Data Types

3.1 Variables

A variable is a named storage location used to hold a value. Each variable has a data type that determines the kind of information it can store.

int age = 20;
float price = 45.50f;
char grade = 'A';
string name = "Rahul";

3.2 Rules for Naming Variables

  • A variable name can contain letters, digits and underscores.
  • It cannot begin with a digit.
  • Spaces are not allowed.
  • Reserved keywords cannot be used.
  • C++ identifiers are case-sensitive.

3.3 Basic Data Types

  • int: Stores integer values.
  • float: Stores floating-point values.
  • double: Stores floating-point values with greater or equal precision than float.
  • char: Stores character values.
  • bool: Stores true or false.
  • void: Represents the absence of a value.

3.4 Constants

A constant represents a value that cannot be modified through its identifier after initialization.

const double PI = 3.14159;

3.5 Type Conversion

Type conversion changes a value from one data type to another. It can happen automatically or through explicit casting.

int number = 10;

double result = static_cast<double>(number) / 3;

cout << result;

3.6 Auto Keyword

The auto keyword allows the compiler to determine a variable's type from its initializer.

auto number = 100;
auto price = 45.50;

Chapter 4: Operators and Expressions

4.1 Introduction

Operators are symbols that perform operations on variables and values. An expression combines operators and operands to produce a result.

4.2 Arithmetic Operators

Arithmetic operators perform mathematical operations.

int a = 10, b = 3;

cout << a + b << endl;
cout << a - b << endl;
cout << a * b << endl;
cout << a / b << endl;
cout << a % b << endl;

4.3 Relational Operators

Relational operators compare two values and produce a Boolean result.

  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to

4.4 Logical Operators

  • && Logical AND
  • || Logical OR
  • ! Logical NOT

4.5 Assignment Operators

Assignment operators store or update values. Examples include =, +=, -=, *= and /=.

4.6 Increment and Decrement

The increment operator increases a value by one, while the decrement operator decreases it by one.

int x = 5;

x++;
cout << x << endl;

x--;
cout << x;

4.7 Conditional Operator

The conditional operator selects one of two expressions depending on a condition.

int a = 10, b = 20;

int maximum = (a > b) ? a : b;

cout << maximum;

Chapter 5: Input and Output

5.1 Introduction

Input and output operations allow a program to communicate with users. C++ provides stream-based input and output facilities through the iostream header.

5.2 cout Statement

The cout object is used to display output on the standard output stream.

#include <iostream>
using namespace std;

int main()
{
    cout << "Welcome to C++";
    return 0;
}

5.3 cin Statement

The cin object reads formatted input from the keyboard. The extraction operator >> is used to receive values.

#include <iostream>
using namespace std;

int main()
{
    int age;

    cout << "Enter your age: ";
    cin >> age;

    cout << "Your age is " << age;

    return 0;
}

5.4 getline() Function

The getline() function reads a complete line of text, including spaces, until a newline character is encountered.

#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name;

    cout << "Enter your full name: ";
    getline(cin, name);

    cout << "Hello " << name;

    return 0;
}

Manipulators help control input and output formatting.

  • endl — inserts a new line and flushes the output stream.
  • setw() — sets the minimum field width.
  • setprecision() — controls floating-point precision.
  • fixed — uses fixed-point floating-point formatting.
#include <iostream>
#include <iomanip>
using namespace std;

int main()
{
    double price = 45.6789;

    cout << fixed << setprecision(2) << price;

    return 0;
}
Important: cin with >> normally reads one word for a string. Use getline() when the complete line is required.

Chapter 6: Decision Making Statements

6.1 Introduction

Decision-making statements allow a program to select different actions according to conditions. They help implement logical decisions in applications.

6.2 if Statement

int age = 20;

if (age >= 18)
{
    cout << "Adult";
}

6.3 if-else Statement

int number = 7;

if (number % 2 == 0)
{
    cout << "Even Number";
}
else
{
    cout << "Odd Number";
}

6.4 else-if Ladder

An else-if ladder checks multiple conditions in sequence.

int marks = 75;

if (marks >= 90)
    cout << "Grade A";
else if (marks >= 70)
    cout << "Grade B";
else if (marks >= 50)
    cout << "Grade C";
else
    cout << "Needs Improvement";

6.5 Nested if

A nested if is an if statement placed inside another if statement. It is useful when a decision depends on multiple conditions.

6.6 switch Statement

The switch statement selects a block according to the value of an integral or enumeration expression.

int choice = 2;

switch(choice)
{
    case 1:
        cout << "Addition";
        break;

    case 2:
        cout << "Subtraction";
        break;

    default:
        cout << "Invalid Choice";
}

6.7 Importance of Decision Making

Decision statements are used in login systems, calculators, banking applications, grading systems and menu-driven programs.

Chapter 7: Looping Statements

7.1 Introduction to Loops

A loop is a programming structure that repeats a block of statements while a specified condition is satisfied. Loops reduce code repetition.

7.2 for Loop

A for loop is commonly used when the number of repetitions is known.

for(int i = 1; i <= 5; i++)
{
    cout << i << endl;
}

7.3 while Loop

A while loop checks the condition before executing its body.

int i = 1;

while(i <= 5)
{
    cout << i << endl;
    i++;
}

7.4 do-while Loop

A do-while loop executes its body at least once because the condition is checked after the body.

int i = 1;

do
{
    cout << i << endl;
    i++;
}
while(i <= 5);

7.5 break Statement

The break statement terminates the nearest enclosing loop or switch statement.

7.6 continue Statement

The continue statement skips the remaining statements of the current iteration and proceeds to the next iteration.

7.7 Nested Loops

A nested loop is a loop inside another loop. It is useful for patterns, tables and matrix operations.

for(int i = 1; i <= 3; i++)
{
    for(int j = 1; j <= 3; j++)
    {
        cout << "* ";
    }

    cout << endl;
}

Chapter 8: Arrays and Strings

8.1 Introduction to Arrays

An array is a collection of elements of the same data type stored in consecutive memory locations. Array indexing starts from zero.

8.2 Array Declaration

int marks[5] = {70, 80, 65, 90, 75};

int numbers[5] = {10, 20, 30, 40, 50};

for(int i = 0; i < 5; i++)

int matrix[2][3] = {

for(int i = 0; i < 2; i++)
{
    for(int j = 0; j < 3; j++)

8.5 Strings in C++

Chapter 9: Functions and Function Overloading

9.1 Meaning of Function

A function is a named block of code that performs a particular task. Functions make programs modular, reusable and easier to maintain.

9.2 Function Declaration

A function declaration informs the compiler about the function name, return type and parameters.

int add(int a, int b);

9.3 Function Definition

int add(int a, int b)
{
    return a + b;
}

9.4 Function Calling

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result = add(10, 20);

    cout << "Sum = " << result;

    return 0;
}

9.5 Types of Functions

  • Function without arguments and without return value.
  • Function with arguments and without return value.
  • Function without arguments and with return value.
  • Function with arguments and with return value.

9.6 Function Overloading

Function overloading allows multiple functions to have the same name with different parameter lists. The compiler selects the appropriate function based on the arguments.

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

double add(double a, double b)
{
    return a + b;
}

int main()
{
    cout << add(10, 20) << endl;
    cout << add(5.5, 2.5);

    return 0;
}

9.7 Recursion

Recursion occurs when a function calls itself. A base condition is necessary to stop recursive calls.

int factorial(int n)
{
    if(n <= 1)
        return 1;

    return n * factorial(n - 1);
}

9.8 Default Arguments

Default arguments provide values that are used when the caller does not supply corresponding arguments.

void greet(string name = "Student")
{
    cout << "Hello " << name;
}

Chapter 10: Classes and Objects

10.1 Introduction

Classes and objects are fundamental concepts of object-oriented programming. A class defines the structure and behavior of objects. An object is an instance of a class.

10.2 Class Definition

A class can contain data members and member functions. It is declared using the class keyword.

class Student
{
public:
    int roll;
    string name;

    void display()
    {
        cout << roll << endl;
        cout << name;
    }
};

10.3 Creating Objects

Objects are created using the class name. Each object has its own non-static data members.

Student s1;

s1.roll = 101;
s1.name = "Amit";

s1.display();

10.4 Access Specifiers

  • Public: Members can be accessed through the class interface from outside the class.
  • Private: Members are accessible to class member functions and specified friends.
  • Protected: Members are accessible within the class, specified friends and derived classes.

10.5 Complete Class Example

#include <iostream>
#include <string>
using namespace std;

class Student
{
private:
    int roll;

public:
    string name;

    void setRoll(int r)
    {
        roll = r;

    void display()
    {
        cout << "Roll: " << roll << endl;

    }
};

int main()
{
    Student s1;

    s1.setRoll(101);
    s1.name = "Rahul";

    s1.display();

    return 0;
}

10.6 Benefits of Classes

  • Organize related data and functions.
  • Support data protection.
  • Make software easier to maintain.
  • Support object-oriented design.
  • Help create reusable software components.

Chapter 11: Constructors and Destructors

11.1 Constructor

A constructor is a special member function that is automatically called when an object is created. Its name is the same as the class name and it has no return type.

11.2 Default Constructor

A default constructor is a constructor that can be called without supplying arguments.

class Student
{
public:
    Student()
    {
        cout << "Object Created";
    }
};

11.3 Parameterized Constructor

A parameterized constructor accepts arguments to initialize an object with specific values.

class Student
{
public:
    int roll;

    Student(int r)
    {
        roll = r;
    }
};

11.4 Copy Constructor

A copy constructor initializes a new object using another object of the same class.

class Student
{
public:
    int roll;

    Student(int r)
    {
        roll = r;
    }

    Student(const Student &s)
    {
        roll = s.roll;
    }
};

11.5 Constructor Overloading

A class can have multiple constructors with different parameter lists. This allows objects to be initialized in different ways.

11.6 Destructor

A destructor is a special member function that is called when an object is destroyed. It has the same name as the class, preceded by a tilde symbol, and has no return type or parameters.

class Demo
{
public:
    Demo()
    {
        cout << "Constructor Called" << endl;
    }

    ~Demo()
    {
        cout << "Destructor Called";
    }
};

11.7 Constructor vs Destructor

  • A constructor initializes an object.
  • A destructor performs cleanup when an object is destroyed.
  • A class can have overloaded constructors.
  • A class has only one destructor, which cannot be overloaded.

Chapter 12: Inheritance

12.1 Introduction

Inheritance is an object-oriented programming feature in which a new class is created using an existing class. The existing class is called the base class, and the new class is called the derived class.

12.2 Basic Syntax

class Base
{
public:
    void display()
    {
        cout << "Base Class";
    }
};

class Derived : public Base
{
};

12.3 Single Inheritance

Single inheritance occurs when one derived class inherits from one base class.

class Animal
{
public:
    void eat()
    {
        cout << "Eating";
    }
};

class Dog : public Animal
{
public:
    void bark()
    {
        cout << "Barking";
    }
};

12.4 Multilevel Inheritance

Multilevel inheritance occurs when a class is derived from another derived class, creating a chain of inheritance.

class A
{
public:
    void showA()
    {
        cout << "Class A";
    }
};

class B : public A
{
};

class C : public B
{
};

12.5 Multiple Inheritance

Multiple inheritance occurs when one derived class inherits from more than one base class.

class Father
{
public:
    void father()
    {
        cout << "Father";
    }
};

class Mother
{
public:
    void mother()
    {
        cout << "Mother";
    }
};

class Child : public Father, public Mother
{
};

12.6 Hierarchical Inheritance

Hierarchical inheritance occurs when multiple derived classes inherit from the same base class.

12.7 Hybrid Inheritance

Hybrid inheritance combines two or more inheritance patterns. Some designs involving multiple inheritance may require virtual base classes to avoid duplicate base subobjects.

12.8 Benefits of Inheritance

  • Promotes code reuse.
  • Reduces repeated code.
  • Supports class hierarchies.
  • Helps implement polymorphism.
  • Improves software organization.

Chapter 13: Polymorphism

13.1 Introduction

Polymorphism means one interface with multiple forms of behavior. It allows the same function name or interface to behave differently depending on the context.

13.2 Types of Polymorphism

  • Compile-time Polymorphism: Resolved during compilation, such as function overloading and operator overloading.
  • Runtime Polymorphism: Achieved through virtual functions and dynamic dispatch.

13.3 Function Overloading

Function overloading allows multiple functions with the same name but different parameter lists.

int area(int side)
{
    return side * side;
}

int area(int length, int width)
{
    return length * width;
}

13.4 Operator Overloading

Operator overloading allows operators to be given a suitable meaning for user-defined types.

class Number
{
public:
    int value;

    Number(int v)
    {
        value = v;
    }

    Number operator+(const Number &n)
    {
        return Number(value + n.value);
    }
};

13.5 Virtual Functions

A virtual function supports runtime polymorphism. When called through a base-class pointer or reference, the appropriate overridden function can be selected according to the actual object type.

class Animal
{
public:
    virtual void sound()
    {
        cout << "Animal Sound";
    }

    virtual ~Animal() = default;
};

class Dog : public Animal
{
public:
    void sound() override
    {
        cout << "Dog Barks";
    }
};

int main()
{
    Dog d;
    Animal *ptr = &d;

    ptr->sound();

    return 0;
}

13.6 Function Overriding

Function overriding occurs when a derived class provides its own implementation of a suitable virtual function declared in the base class.

13.7 Benefits of Polymorphism

  • Provides flexible program design.
  • Supports reusable interfaces.
  • Improves extensibility.
  • Reduces dependency on specific object types.

Chapter 14: Encapsulation and Abstraction

14.1 Encapsulation

Encapsulation is the process of combining data and related functions into a single unit, such as a class. Access specifiers help control how the internal data is accessed.

14.2 Example of Encapsulation

class BankAccount
{
private:
    double balance = 0;

public:
    void deposit(double amount)
    {
        if(amount > 0)
            balance += amount;
    }

    double getBalance()
    {
        return balance;
    }
};

14.3 Benefits of Encapsulation

  • Protects internal data.
  • Controls access to class members.
  • Improves code organization.
  • Makes maintenance easier.

14.4 Abstraction

Abstraction means showing essential features while hiding unnecessary implementation details. It helps users interact with a simple interface without needing to understand the internal working.

14.5 Abstract Classes

An abstract class contains at least one pure virtual function. It cannot be directly instantiated, but it can be used as a base class.

class Shape
{
public:
    virtual void draw() = 0;

    virtual ~Shape() = default;
};

class Circle : public Shape
{
public:
    void draw() override
    {
        cout << "Drawing Circle";
    }
};

14.6 Encapsulation vs Abstraction

  • Encapsulation focuses on grouping data and functions and controlling access.
  • Abstraction focuses on exposing essential functionality while hiding implementation details.
  • Both concepts help develop organized and maintainable software.

14.7 Real-Life Examples

A banking application can hide internal account calculations while showing simple deposit and balance operations. A car interface exposes steering and braking controls without requiring the driver to understand every internal mechanism.

Chapter 15: Pointers and File Handling

15.1 Pointers

A pointer is a variable that stores the memory address of another object. Pointers are useful for working with dynamically allocated memory and passing objects efficiently.

15.2 Pointer Example

#include <iostream>
using namespace std;

int main()
{
    int number = 100;
    int *ptr = &number;

    cout << "Value: " << *ptr << endl;
    cout << "Address: " << ptr;

    return 0;
}

15.3 Smart Pointers

C++ provides smart pointers in the memory header. They help manage dynamically allocated objects through automatic resource management.

  • unique_ptr — represents exclusive ownership.
  • shared_ptr — allows shared ownership.
  • weak_ptr — provides a non-owning reference to an object managed by shared_ptr.

15.4 Introduction to File Handling

File handling allows programs to store information in files and retrieve it later. C++ provides file stream classes through the fstream header.

15.5 File Stream Classes

  • ifstream: Used for reading from files.
  • ofstream: Used for writing to files.
  • fstream: Supports reading and writing.

15.6 Writing to a File

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ofstream file("student.txt");

    if(file.is_open())
    {
        file << "Smart Digital Library";
        file.close();
    }

    return 0;
}

15.7 Reading from a File

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    ifstream file("student.txt");
    string line;

    if(file.is_open())
    {
        while(getline(file, line))
        {
            cout << line << endl;
        }

        file.close();
    }

    return 0;
}

15.8 File Opening Modes

  • ios::in — opens for reading.
  • ios::out — opens for writing.
  • ios::app — appends data.
  • ios::binary — opens in binary mode.
  • ios::trunc — truncates existing contents.
Important: Check whether a file opened successfully before performing read or write operations.

16.2 Project 1: Simple Calculator

This calculator accepts two numbers and an operator, then performs the selected arithmetic operation.

#include <iostream>
using namespace std;

int main()
{
    double a, b;
    char op;

    cout << "Enter first number: ";
    cin >> a;

    cout << "Enter operator (+,-,*,/): ";
    cin >> op;

    cout << "Enter second number: ";
    cin >> b;

    switch(op)
    {
        case '+':
            cout << "Result = " << a + b;
            break;

        case '-':
            cout << "Result = " << a - b;
            break;

        case '*':
            cout << "Result = " << a * b;
            break;

        case '/':
            if(b != 0)
                cout << "Result = " << a / b;
            else
                cout << "Division by zero is not allowed";
            break;

        default:
            cout << "Invalid Operator";
    }

    return 0;
}

16.3 Project 2: Student Management System

A student management system stores student information such as roll number, name and marks. Classes and objects can organize the records.

#include <iostream>
#include <string>
using namespace std;

class Student
{
public:
    int roll;
    string name;

    {
        cout << "Enter Roll Number: ";
        cin >> roll;

        cout << "Enter Name: ";

        cout << "Enter Marks: ";
        cin >> marks;

    {

}

Glossary

  • Class: A blueprint used to create objects.
  • Object: An instance of a class.
  • Constructor: A special function used to initialize objects.
  • Destructor: A special function called when an object is destroyed.
  • Inheritance: A mechanism for deriving a class from another class.
  • Polymorphism: The ability to provide different behaviors through a common interface.
  • Encapsulation: Combining data and functions into a single unit.
  • Abstraction: Hiding implementation details while exposing essential features.
  • Pointer: A variable that stores a memory address.
  • Function: A named block of reusable code.
  • Overloading: Using the same function or operator name with different parameter types or meanings.
  • Overriding: Providing a derived-class implementation of a virtual base-class function.
  • Array: A collection of elements of the same type.
  • String: A sequence of characters.
  • Namespace: A named scope used to organize identifiers.
  • Vector: A dynamic sequence container in the C++ standard library.
  • Compiler: A program that translates source code.
  • File Handling: Reading and writing data using files.
  • Template: A feature used to write generic code.
  • Smart Pointer: An object that helps manage dynamically allocated resources.
