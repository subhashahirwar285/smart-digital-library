Preface

C is a general-purpose programming language that has played an important role in the development of modern software. It is widely studied because it teaches fundamental programming concepts, structured problem solving and the relationship between software and computer memory.

This textbook introduces C programming from the basics to intermediate concepts. Students will learn how to write programs, use variables, work with operators, control program flow, manage arrays and strings, create functions and understand pointers.

The book also covers structures, dynamic memory allocation, file handling and practical project development. Each chapter includes explanations, sample programs and practice questions.

How to use this book: Read each topic, type the sample programs in a C compiler, run them and experiment by changing the input values.

Learning Outcomes

  • Understand the fundamentals and structure of C programs.
  • Use variables, data types, operators and control statements.
  • Develop programs using arrays, strings and functions.
  • Understand pointers and memory management.
  • Work with structures and files.
  • Develop small programming projects using C.

Chapter 1: Introduction to C Programming

1.1 What is C?

C is a general-purpose, procedural programming language developed by Dennis Ritchie at Bell Laboratories in the early 1970s. It became popular because it provides efficient execution, structured programming features and low-level memory access through pointers.

1.2 History of C

C developed from earlier languages such as BCPL and B. It was created to support the development of the UNIX operating system. The language later became widely used in system software, embedded systems, compilers and application development.

1.3 Features of C

  • Simple structure: Provides a relatively small set of core language features.
  • Portable: Programs can often be adapted to different platforms with limited changes.
  • Procedural: Programs can be organized into functions.
  • Efficient: Compiled C programs can execute with high performance.
  • Pointer support: Allows direct manipulation of memory addresses.
  • Rich operators: Provides arithmetic, logical, relational and bitwise operators.

1.4 Applications of C

C is used in operating systems, embedded devices, device drivers, compilers, networking software, database engines and performance-sensitive applications.

1.5 Compiler and Interpreter

A compiler translates source code into another form, commonly machine code or object code, before execution. An interpreter executes program instructions through an interpretation process. C is generally used as a compiled language.

Example: A C compiler such as GCC can translate a source file named hello.c into an executable program.

Chapter 2: Structure of a C Program

2.1 Basic Program Structure

A C program usually contains preprocessor directives, function definitions and statements. The main() function is the standard entry point of a hosted C program.

2.2 First C Program

#include <stdio.h>

int main(void)
{
    printf("Hello, World!");
    return 0;
}

2.3 Explanation

  • #include <stdio.h> makes standard input/output declarations available.
  • int main(void) defines the main function.
  • { } mark the beginning and end of a block.
  • printf() displays formatted output.
  • return 0; indicates successful completion.

2.4 Comments

Comments explain program logic and are ignored by the compiler. C supports single-line and multi-line comments.

// This is a single-line comment

/*
This is a
multi-line comment
*/

2.5 Compilation and Execution

Save the program with a .c extension. With GCC installed, open a terminal in the file's directory and use:

gcc hello.c -o hello
./hello

On Windows, the executable can commonly be run with:

gcc hello.c -o hello.exe
hello.exe
Important: The exact execution command depends on the operating system and compiler setup.

Chapter 3: Variables, Constants and Data Types

3.1 Variables

A variable is a named object used to store a value during program execution. Every variable has a type that determines the kind of value it can store.

int age = 20;
float price = 45.50f;
char grade = 'A';

3.2 Rules for Naming Variables

  • A name may contain letters, digits and underscores.
  • A name cannot begin with a digit.
  • Spaces are not allowed.
  • C keywords cannot be used as variable names.
  • Names are case-sensitive.

3.3 Basic Data Types

  • int: Stores integer values.
  • char: Stores a character value.
  • float: Stores floating-point values.
  • double: Provides a floating-point type with at least as much precision as float.
  • void: Represents the absence of a value or type in specific contexts.

3.4 Type Modifiers

Modifiers such as short, long, signed and unsigned can modify certain integer types. Exact sizes depend on the compiler and platform.

3.5 Constants

A constant is a value that should not be modified during its intended use. The const keyword can make an object read-only through a particular identifier.

const float PI = 3.14159f;

3.6 Type Conversion

Type conversion changes a value from one type to another. Some conversions happen automatically, while explicit casts allow programmers to request a conversion.

int number = 10;
float result = (float)number / 3;

Chapter 4: Operators and Expressions

4.1 Meaning of Operators

Operators are symbols that perform operations on values or variables. An expression combines operands and operators to produce a result.

4.2 Arithmetic Operators

The main arithmetic operators are addition (+), subtraction (-), multiplication (*), division (/) and remainder (%).

int a = 10, b = 3;

printf("%d", a + b);
printf("%d", a - b);
printf("%d", a * b);
printf("%d", a / b);
printf("%d", a % b);

4.3 Relational Operators

Relational operators compare values and produce an integer result of 1 for true or 0 for false in C. They include ==, !=, >, <, >= and <=.

4.4 Logical Operators

  • && — logical AND.
  • || — logical OR.
  • ! — logical NOT.

4.5 Assignment and Increment Operators

The assignment operator = stores a value. Compound assignments include +=, -= and *=. Increment and decrement operators are ++ and --.

4.6 Conditional Operator

The conditional operator ?: selects one of two expressions depending on a condition.

int a = 10, b = 20;
int maximum = (a > b) ? a : b;

4.7 Operator Precedence

When an expression contains multiple operators, precedence rules determine the order of evaluation. Parentheses can make the intended order clear.

Chapter 5: Input and Output Functions

5.1 Standard Input and Output

C provides standard input and output functions through the stdio.h header. These functions allow programs to communicate with users through text input and output.

5.2 printf() Function

The printf() function displays formatted output on the standard output stream.

#include <stdio.h>

int main(void)
{
    int age = 20;
    printf("My age is %d", age);
    return 0;
}

5.3 scanf() Function

The scanf() function reads formatted input. For most ordinary variables, the address operator & is used to pass the variable's address.

#include <stdio.h>

int main(void)
{
    int number;

    printf("Enter a number: ");
    if (scanf("%d", &number) == 1)
    {
        printf("You entered %d", number);
    }

    return 0;
}

5.4 Format Specifiers

  • %d — int
  • %c — character
  • %f — floating-point output
  • %lf — double input with scanf
  • %s — character string

5.5 Escape Sequences

Escape sequences represent special characters. Common examples are \n for a new line, \t for a tab and \\ for a backslash.

Safety tip: Always check the return value of input functions. Avoid using unbounded string input because it can overflow a character array.

Chapter 6: Decision Making Statements

6.1 Introduction

Decision-making statements allow a program to select different actions depending on whether a condition is true or false. They are essential for building logic into a program.

6.2 if Statement

int age = 20;

if (age >= 18)
{
    printf("Eligible by age condition");
}

6.3 if-else Statement

int number = 7;

if (number % 2 == 0)
{
    printf("Even number");
}
else
{
    printf("Odd number");
}

6.4 else-if Ladder

An else-if ladder checks multiple conditions in sequence. The first true condition determines which block is executed.

int marks = 75;

if (marks >= 90)
    printf("Grade A");
else if (marks >= 70)
    printf("Grade B");
else if (marks >= 50)
    printf("Grade C");
else
    printf("Needs improvement");

6.5 Nested if

A nested if is an if statement placed inside another if or else block. It is useful when a decision depends on more than one level of conditions.

6.6 switch Statement

The switch statement selects a branch based on an integer-like controlling expression, including integer and enumeration values.

int choice = 2;

switch (choice)
{
    case 1:
        printf("Add");
        break;
    case 2:
        printf("Subtract");
        break;
    default:
        printf("Invalid choice");
}

Chapter 7: Looping Statements

7.1 Meaning of Loops

A loop repeats a block of code while a specified condition is satisfied. Loops reduce repeated statements and make programs more organized.

7.2 for Loop

A for loop is useful when the initialization, condition and update steps can be written together.

for (int i = 1; i <= 5; i++)
{
    printf("%d\n", i);
}

7.3 while Loop

A while loop checks its condition before each iteration. If the condition is initially false, the loop body does not execute.

int i = 1;

while (i <= 5)
{
    printf("%d\n", i);
    i++;
}

7.4 do-while Loop

A do-while loop checks its condition after executing the loop body. Therefore, the body executes at least once.

int i = 1;

do
{
    printf("%d\n", i);
    i++;
}
while (i <= 5);

7.5 break Statement

The break statement terminates the nearest enclosing loop or switch statement.

7.6 continue Statement

The continue statement skips the remaining statements in the current loop iteration and moves to the next iteration when appropriate.

7.7 Nested Loops

A nested loop is a loop inside another loop. It is often used for tables, patterns and two-dimensional arrays.

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        printf("* ");
    }
    printf("\n");
}

Chapter 8: Arrays

8.1 Meaning of Array

An array is a collection of elements of the same type stored in consecutive memory locations. It allows a program to work with multiple related values using one variable name.

8.2 Declaration and Initialization

int marks[5] = {70, 80, 65, 90, 75};

Array indexing begins at zero. In the example, the first element is marks[0] and the last is marks[4].

8.3 Accessing Array Elements

int numbers[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++)
{
    printf("%d\n", numbers[i]);
}

8.4 One-Dimensional Array

A one-dimensional array stores a sequence of values. It is useful for marks, prices, scores and other lists of similar data.

8.5 Two-Dimensional Array

A two-dimensional array is organized into rows and columns. It can represent a matrix or table.

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int i = 0; i < 2; i++)
{
    for (int j = 0; j < 3; j++)
    {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}

8.6 Common Array Operations

Common operations include traversal, searching, updating and sorting. When accessing an array, always ensure the index is within its valid range.

Important: Accessing an element outside an array's bounds causes undefined behavior in C.

Chapter 9: Strings in C

9.1 Meaning of String

C does not have a separate built-in string data type. A string is commonly represented as an array of characters terminated by a null character, written as '\0'.

9.2 String Declaration

char name[20] = "Rahul";

The array has enough space for the characters and the terminating null character.

9.3 Reading and Displaying Strings

#include <stdio.h>

int main(void)
{
    char name[50];

    printf("Enter your name: ");

    if (fgets(name, sizeof name, stdin) != NULL)
    {
        printf("Hello %s", name);
    }

    return 0;
}

9.4 String Library Functions

The string.h header provides commonly used functions for working with null-terminated strings.

  • strlen() calculates string length, excluding the terminating null character.
  • strcpy() copies a string into another character array.
  • strcat() appends one string to another.
  • strcmp() compares two strings.

9.5 Example of String Length

#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "Programming";
    printf("Length = %zu", strlen(text));
    return 0;
}

9.6 Common String Errors

Common errors include forgetting space for the null terminator, accessing characters outside the array and copying a string into a destination that is too small. Always check the available buffer size.

Chapter 10: Functions

10.1 Meaning of Function

A function is a named block of code that performs a particular task. Functions help divide a large program into smaller, reusable and easier-to-test units.

10.2 Function Declaration

A function declaration, also called a prototype, tells the compiler about the function's name, return type and parameters.

int add(int a, int b);

10.3 Function Definition and Call

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int result = add(10, 20);
    printf("Sum = %d", result);
    return 0;
}

10.4 Types of Functions

  • Functions with no arguments and no return value.
  • Functions with arguments and no return value.
  • Functions with no arguments and a return value.
  • Functions with arguments and a return value.

10.5 Call by Value

In C, function arguments are passed by value. The function receives its own parameter value, so modifying that parameter does not directly change the caller's original variable.

10.6 Recursion

Recursion occurs when a function calls itself. A recursive function needs a base condition to stop further calls.

int factorial(int n)
{
    if (n <= 1)
        return 1;

    return n * factorial(n - 1);
}

10.7 Benefits of Functions

Functions improve code reuse, readability, testing and maintenance. A well-designed function should generally perform one clearly defined task.

Chapter 11: Pointers

11.1 Meaning of Pointer

A pointer is a variable that stores the memory address of another object or function. Pointers are an important feature of C because they support efficient data access, dynamic memory allocation and flexible data structures.

11.2 Pointer Declaration

int number = 10;
int *ptr = &number;

The address-of operator & obtains an object's address. The dereference operator * accesses the value through a valid pointer.

11.3 Accessing a Value

#include <stdio.h>

int main(void)
{
    int number = 10;
    int *ptr = &number;

    printf("Value = %d\n", *ptr);
    printf("Address = %p\n", (void *)ptr);

    return 0;
}

11.4 NULL Pointer

A null pointer does not point to a valid object or function. It is useful for representing the absence of a valid address. A pointer should be checked before dereferencing when it may be null.

11.5 Pointer Arithmetic

Pointer arithmetic allows movement between elements of an array. Adding one to a pointer advances it by the size of the pointed-to type. Such operations must remain within the relevant array object or one position past its end.

11.6 Pointers and Arrays

In many expressions, an array name is converted to a pointer to its first element. This relationship makes pointers useful for processing arrays and passing array data to functions.

11.7 Pointer to Pointer

A pointer to pointer stores the address of another pointer. It is declared using two asterisks, for example int **ptr;.

Important: Never dereference an uninitialized, invalid or freed pointer. Doing so can cause undefined behavior.

Chapter 12: Structures and Unions

12.1 Structure

A structure is a user-defined data type that groups related variables, possibly of different types, under one name. Each member has its own storage within the structure object.

12.2 Structure Declaration

struct Student
{
    int roll;
    char name[30];
    float marks;
};

12.3 Structure Variable

struct Student s1 = {1, "Amit", 85.5f};

printf("%d", s1.roll);
printf("%s", s1.name);
printf("%.2f", s1.marks);

12.4 Accessing Members

The dot operator accesses a member through a structure variable. The arrow operator accesses a member through a pointer to a structure.

struct Student *ptr = &s1;
printf("%s", ptr->name);

12.5 Array of Structures

An array of structures stores multiple records of the same structure type. It is useful for student lists, employee records and product information.

12.6 Union

A union is a user-defined type in which its members share the same memory area. Its size is sufficient to hold its largest member, subject to alignment requirements. Typically, only one member's stored value is used at a time.

union Data
{
    int number;
    float price;
    char letter;
};

12.7 Structure vs Union

In a structure, members have separate storage. In a union, members share storage. A structure is useful for keeping several values together, while a union can be useful when different alternatives share the same memory space.

Chapter 13: Dynamic Memory Allocation

13.1 Meaning

Dynamic memory allocation allows a program to request memory while it is running. This is useful when the required amount of memory is not known in advance.

13.2 Memory Management Functions

The stdlib.h header provides functions such as malloc(), calloc(), realloc() and free().

  • malloc(): Allocates a block of memory of the requested size. The contents are uninitialized.
  • calloc(): Allocates space for multiple elements and initializes the allocated bytes to zero.
  • realloc(): Changes the size of a previously allocated block.
  • free(): Releases dynamically allocated memory.

13.3 malloc() Example

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *numbers = malloc(5 * sizeof *numbers);

    if (numbers == NULL)
        return 1;

    for (int i = 0; i < 5; i++)
        numbers[i] = (i + 1) * 10;

    for (int i = 0; i < 5; i++)
        printf("%d ", numbers[i]);

    free(numbers);
    return 0;
}

13.4 Memory Management Rules

  • Check whether allocation functions returned NULL.
  • Allocate enough memory for the required elements.
  • Do not use memory after it has been freed.
  • Release memory when it is no longer needed.
  • Do not free the same allocated block more than once.

13.5 Memory Leaks

A memory leak occurs when allocated memory is no longer reachable or needed but has not been released. Careful ownership and cleanup practices help prevent memory leaks.

Chapter 14: File Handling in C

14.1 Introduction

File handling allows a C program to store information in files and retrieve it later. It is useful when data must remain available after a program finishes.

14.2 FILE Pointer

C uses the FILE type, declared in stdio.h, to represent a stream associated with a file.

14.3 Opening a File

The fopen() function opens a file and returns a file pointer. If opening fails, it returns NULL.

FILE *fp = fopen("data.txt", "w");

if (fp == NULL)
{
    printf("Unable to open file");
}

14.4 File Modes

  • r — open an existing file for reading.
  • w — open for writing; create or truncate the file.
  • a — open for appending; create if necessary.
  • r+ — open an existing file for reading and writing.
  • w+ — open for reading and writing, creating or truncating the file.
  • a+ — open for reading and appending.

14.5 Writing to a File

#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "w");

    if (fp == NULL)
        return 1;

    fprintf(fp, "Welcome to C programming");
    fclose(fp);

    return 0;
}

14.6 Reading from a File

char line[100];
FILE *fp = fopen("data.txt", "r");

if (fp != NULL)
{
    while (fgets(line, sizeof line, fp) != NULL)
    {
        printf("%s", line);
    }

    fclose(fp);
}

14.7 Closing a File

The fclose() function closes an open file stream and helps ensure that buffered output is properly handled. Always check file-opening results before using a file pointer.

Chapter 15: Preprocessor and Header Files

15.1 Preprocessor

The C preprocessor performs operations on source code before the main compilation stage. Preprocessor directives begin with the hash symbol #.

15.2 #include Directive

The include directive makes declarations from a header file available to the program.

#include <stdio.h>
#include <string.h>

15.3 #define Directive

The define directive creates a macro. A macro can represent a constant-like replacement or a function-like expression.

#define MAX_SIZE 100

int numbers[MAX_SIZE];

15.4 Conditional Compilation

Directives such as #if, #ifdef, #ifndef, #else and #endif control which parts of source code are included in a compilation.

#define DEBUG

#ifdef DEBUG
printf("Debug mode enabled");
#endif

15.5 Header Files

Header files commonly contain function declarations, macros, type definitions and other shared declarations. Standard headers include stdio.h, stdlib.h, string.h and math.h.

15.6 Benefits

Preprocessor directives help organize reusable declarations, configure builds and share definitions between source files. Macros should be written carefully because they perform textual substitution rather than ordinary function calls.

Chapter 16: Practical C Programming Projects

16.1 Why Build Projects?

Practical projects help students apply programming concepts to real problems. They improve logical thinking, debugging skills and the ability to organize a program into functions and data structures.

16.2 Project 1: Simple Calculator

This project accepts two numbers and an operator, then performs the selected arithmetic operation.

#include <stdio.h>

int main(void)
{
    double a, b;
    char op;

    printf("Enter expression (example: 10 + 5): ");

    if (scanf("%lf %c %lf", &a, &op, &b) != 3)
        return 1;

    switch (op)
    {
        case '+':
            printf("Result = %.2f", a + b);
            break;
        case '-':
            printf("Result = %.2f", a - b);
            break;
        case '*':
            printf("Result = %.2f", a * b);
            break;
        case '/':
            if (b != 0)
                printf("Result = %.2f", a / b);
            else
                printf("Division by zero is not allowed");
            break;
        default:
            printf("Invalid operator");
    }

    return 0;
}

16.3 Project 2: Student Record System

A student record system can store a student's roll number, name and marks using a structure. An array of structures can hold multiple records. Functions can be created to add, display and search for students.

16.4 Project 3: Contact Management System

A contact management program can store names and phone numbers. It can provide options to add contacts, display saved contacts and search by name. File handling can be used to preserve records between program runs.

16.5 Project Development Steps

  1. Understand the problem and define the requirements.
  2. Design the program flow and data structures.
  3. Divide the work into smaller functions.
  4. Write and compile the source code.
  5. Test normal, boundary and invalid inputs.
  6. Fix errors and improve readability.
  7. Document how the program works.

16.6 Good Programming Practices

  • Use meaningful variable and function names.
  • Keep functions focused on a single task.
  • Validate user input.
  • Check the results of file and memory operations.
  • Use comments to explain complex logic.
  • Compile with warnings enabled and test thoroughly.

Glossary

  • Algorithm: A step-by-step method for solving a problem.
  • Array: A collection of elements of the same type.
  • Compiler: A program that translates source code.
  • Constant: A value intended not to change during its use.
  • Data Type: Defines the kind of value an object can store.
  • Function: A named block of reusable code.
  • Loop: A statement that repeats a block of code.
  • Pointer: An object that stores a memory address.
  • Recursion: A technique in which a function calls itself.
  • Structure: A user-defined type that groups related members.
  • Union: A type whose members share storage.
  • Variable: A named object that stores a value.
  • String: A sequence of characters terminated by a null character.
  • Memory Leak: Allocated memory that is not properly released.
  • File Handling: Reading and writing data using file streams.
  • Header File: A file containing declarations shared by source files.
